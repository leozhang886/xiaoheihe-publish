# 小黑盒封面规则

> 来源：小黑盒官方发布设置提示 + 电玩帮《人人都可以打造的爆款文章封面》+ 我们自己三个月的实测。
> 整理时间：2026-10-30。

---

## 一、硬指标

| 项 | 要求 |
|---|---|
| **头条封面尺寸** | **不低于 900×480**（官方原话） |
| 我们用的尺寸 | **1200×675**（16:9，超过下限，实测可用） |
| 格式 | PNG，单张控制在 1.5 MB 以内 |
| 封面来源 | **正文第一张图就是封面**，没有单独的封面上传框 |

---

## 二、什么封面有效（按重要性排）

### 1. 背景越简单越好

原教程的原话：**「简单的背景往往更出效果」**。

纯色或者柔和渐变打底，上面只放文字。

**不要往背景上堆装饰元素**——会显得杂乱、多余、不够凝练。

> 参考物：《新世纪福音战士》的海报，大面积纯色 + 干净文字，反而有冲击力。

### 2. 视觉重心偏右

这是小黑盒特有的。

原教程：**「小黑盒的文章瀑布流中，视觉重心偏向右侧。」**

所以右侧应该放**信息量最大的东西**（主数字、关键结论、或者主体画面）。

**我们现在的封面全是左对齐**，右上是吉祥物贴纸。这条要调整。

### 3. 用「大而截断的文字」

原教程称这是「最出效果的设计技巧」。

做法：**把某个字或者数字放大到超出画面边缘**，让它被裁掉一部分。

原理是利用大脑的补全本能——看到不完整的东西会下意识想补全，视线就停住了。

**我们已经在用**：`1 亿`、`5 个`、`32 万` 这种大数字，可以考虑再放大约 20% 并故意截断。

### 4. 渐变引导视线

渐变能带视线流动，指向关键信息。

**但明度过低的渐变会显得生硬严肃**——深色封面要留一点亮部。

### 5. 减少干扰 = 提升信息传递

原教程的总结：**「根本不需要太复杂的设计。减少干扰，其实就是在提升内容的有效性。」**

判断标准很简单：**手机缩略图大小下，还能一眼看清主标题吗？**

## 三、封面配方（我们验证过的两种）

### A 型：真实截图 + 压暗 + 标题

**适用**：新闻类、游戏相关。

- 底图用官方截图（Steam CDN 或官方 Press Kit）
- 左侧压暗（`k = 1 - x/(W*0.68)` 的渐变遮罩）
- 标题左对齐，主色区分两行
- 顶部小胶囊放日期或者来源

**优点**：真实、有质感，符合「新闻要配真图」的要求。

### B 型：纯色/渐变 + 大数字 + 三条要点

**适用**：实用类、数据类。

- 深色线性渐变打底
- 主标题两行，第二行用强调色
- 中间放一个超大数字（120pt 以上）
- 下面三行要点，每行带左侧色条

**优点**：扫读性最好，缩略图里也能看清。

## 四、图源清单

按可靠性排序：

| 类型 | 来源 | 备注 |
|---|---|---|
| 游戏官方截图 | Steam 商店接口 `screenshots[].path_full` | 1920×1080，最稳 |
| 官方主视觉 | Steam `header_image` / `capsule_imagev5` | 直接可用 |
| 官方 Press Kit | 开发商官网 | 例如 Keen Games 的 `download.enshrouded.com/Press Kit/` |
| 赛事官方 | 官方微博、官方新闻页 | 例如英雄联盟赛事微博 |
| 媒体报道配图 | 17173、快科技、搜狐 | `node tools/list-images.mjs <url>` 抓 |
| 免费图库 | Unsplash、Pexels | 只在没有官方图时兜底，游戏稿一般用不上 |

**取图原则**：

- **优先用游戏自己的官方素材**，比图库好看也更贴题
- 用了别人的图**必须标来源**
- 别用别的玩家的截图冒充自己的

## 五、做封面的工具

现成的脚本在 `tools/` 下：

- `make_news_covers.py` —— A 型（真实截图 + 标题）
- `make_1028_covers.py` / `make_1026_covers.py` —— B 型（渐变 + 大数字）
- `add_mascot.py` —— 给封面右上角贴吉祥物，`--only <文件名>` 只处理一张

**注意**：跑 `add_mascot.py` 不带 `--only` 会给**所有**封面再盖一次贴纸，会重影。
