# 小黑盒「文章计划」（创作激励）规则

来源：https://www.xiaoheihe.cn/community/creation_plan_intro?type=article
抓取时间：2026-10-30

## 核心条件

| 条件 | 要求 |
|---|---|
| 格式 | 必须是**文章** |
| 内容类型 | **非新闻消息**（硬性） |
| 字数 | 推荐 **500-1500 字**，避免过长 |
| 图片 | 真实、清晰、美观，符合主题 |
| 原创 | 必须原创 |
| 加分项 | 添加合适的话题 |

**选题举例**：游戏攻略、游戏赏析、科技测评、创作。

## 能拿到什么

- **现金奖励**：按浏览数据与互动数据给，数据涨了收益也涨
- **额外流量**：首页更多推荐
- **全站热点**：有机会上

## 关键 Q&A

- **一篇内容最多只能参加一个激励计划**（不能同时报多个）
- **选错计划 = 无法通过审核 + 拿不到任何奖励**
- 奖励发放会有站内信提示（首页右上角邮件图标）
- 收益数据看：「首页」→「我」→ 右滑 →「创作中心」→「数据中心」

## 对我们意味着什么

**这是最要紧的一条：新闻稿不参与文章计划，拿不到钱。**

所以按收益排优先级：

| 类型 | 能不能拿钱 | 举例 |
|---|---|---|
| 实用技巧 / 攻略 | ✅ 能 | 显卡驱动怎么装、手柄死区、存档备份 |
| 科技测评 / 选购 | ✅ 能 | 显示器验货、键盘轴体、电视当显示器 |
| 行业观察（非新闻） | ✅ 大概率能 | 怀旧服为什么回来、国产 3A 定价 |
| **新闻（发售、赛事、人事）** | ❌ **不能** | 影之刃零发售、LPL 出局、Arkane 关闭 |

**结论：想赚钱就多写实用类和深度类，新闻稿只赚流量不赚钱。**

## 编辑器里的两个开关

- `.creation-plan-join` → 创作计划
- `.cm-task-join` → 创作任务

**两个开关都存不进草稿**，只在真正发布时生效。
提前切换会破坏草稿保存（URL 退化成 `local_xxx`）。

`publish.mjs` 的 `joinCreationPlans()` 只在 `--publish` 分支调用。

# 附：热点计划（2026-11-01 用户提供的官方说明）

**定位**：专为**新闻资讯类内容**设立。鼓励客观、真实的热点内容。

## 与文章计划的区别（最重要）

| | 文章计划 | 热点计划 |
|---|---|---|
| 内容类型 | **非新闻** | **必须新闻** |
| 字数 | 500-1500 字 | **50-200 字左右为佳** |
| 格式 | 不限 | 不限（但要图文并茂） |
| 奖励 | 现金 | 黑盒余额 / 黑盒收益 |

**两者互斥，一篇只能报一个。选错拿不到奖励。**

## 参与资格（热点计划）

- 创作者等级 **> 13**
- 30 天内无违规
- **活跃粉丝量 ≥ 50**（近期有过阅读/点赞/评论/收藏的粉丝）
- **30 天内发布资讯数量 ≥ 5**

## 注意

- 参与后更新频率低于 **30 天/篇** 会被取消资格
- 引战、消息不实等内容过多会被取消资格
- 违规封号或社区警告超 2 次会被取消资格
- 黑盒收益奖励需创作等级到 **Lv.2** 后在创作中心权益页开通

## 结论：选题决定报哪个计划

- **写实用类长文（600-1200 字）** → 文章计划
- **写新闻短资讯（50-200 字）** → 热点计划

**不要拿长文去报热点计划，字数就超了；也不要拿新闻去报文章计划，类型就不符。**

# 附：文章计划官方完整说明（2026-11-01 用户提供）

**定位**：专为**非新闻资讯类深度内容**设立。鼓励游戏攻略、评测赏析等有深度的原创文章。

## 内容要求

| 项 | 要求 |
|---|---|
| 格式 | 发布时选【文章】 |
| 内容 | **非新闻消息**（硬性） |
| 字数 | 推荐 **500-1500 字** |
| 图片 | 真实、清晰、美观，符合主题 |
| 加分 | 添加合适的话题 |

**选题举例**：游戏攻略、游戏赏析、科技测评、创作

## 参与资格（四条门槛）

- 创作者等级 **> 1**
- 30 天内无违规行为
- **活跃粉丝量 ≥ 50**（近期有阅读/点赞/评论/收藏的粉丝）
- **30 天内发布内容数量 ≥ 2**

## 奖励

- **现金**：黑盒余额 / 黑盒收益（收益需创作等级到 **Lv.2** 后在创作中心权益页开通）
- 额外流量曝光
- 有机会进全站热点

## 会被取消资格的情况

- 更新频率 **低于 30 天/篇**
- 存在**引战、商业倾向过强、擦边色情**等低质内容
- 违规封号，或社区违规被警告超过 **2 次**

**注意「商业倾向过强」这条**——选购推荐、导购类文章有被判定风险，写的时候别写成软广。
