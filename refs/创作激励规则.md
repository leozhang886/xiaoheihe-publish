# 小黑盒「文章计划」（创作激励）规则

来源：https://www.xiaoheihe.cn/community/creation_plan_intro?type=article
抓取时间：2026-10-30

## 核心条件

| 条件 | 要求 |
|---|---|
| 格式 | 必须是**文章** |
| 内容类型 | **非新闻消息**（硬性） |
| 字数 | 推荐 **500-1500 字**，避免过长 |
| 图片 | 真实、清晰、美观，符合主题 |
| 原创 | 必须原创 |
| 加分项 | 添加合适的话题 |

**选题举例**：游戏攻略、游戏赏析、科技测评、创作。

## 能拿到什么

- **现金奖励**：按浏览数据与互动数据给，数据涨了收益也涨
- **额外流量**：首页更多推荐
- **全站热点**：有机会上

## 关键 Q&A

- **一篇内容最多只能参加一个激励计划**（不能同时报多个）
- **选错计划 = 无法通过审核 + 拿不到任何奖励**
- 奖励发放会有站内信提示（首页右上角邮件图标）
- 收益数据看：「首页」→「我」→ 右滑 →「创作中心」→「数据中心」

## 对我们意味着什么

**这是最要紧的一条：新闻稿不参与文章计划，拿不到钱。**

所以按收益排优先级：

| 类型 | 能不能拿钱 | 举例 |
|---|---|---|
| 实用技巧 / 攻略 | ✅ 能 | 显卡驱动怎么装、手柄死区、存档备份 |
| 科技测评 / 选购 | ✅ 能 | 显示器验货、键盘轴体、电视当显示器 |
| 行业观察（非新闻） | ✅ 大概率能 | 怀旧服为什么回来、国产 3A 定价 |
| **新闻（发售、赛事、人事）** | ❌ **不能** | 影之刃零发售、LPL 出局、Arkane 关闭 |

**结论：想赚钱就多写实用类和深度类，新闻稿只赚流量不赚钱。**

## 编辑器里的两个开关

- `.creation-plan-join` → 创作计划
- `.cm-task-join` → 创作任务

**两个开关都存不进草稿**，只在真正发布时生效。
提前切换会破坏草稿保存（URL 退化成 `local_xxx`）。

`publish.mjs` 的 `joinCreationPlans()` 只在 `--publish` 分支调用。
