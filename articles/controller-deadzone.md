先说结论：

**默认死区通常偏大，因为它是按"最差的那只手柄"设计的。**

调小能提升精度，但调太小会漂。

这篇讲清楚什么时候该动、动了会发生什么。

# 一、死区是什么

摇杆的中心，理论上应该是「完全回中 = 零输入」。

但现实里不是。

机械结构有公差，弹簧回不到绝对值零，传感器有零点偏移。

**所以厂商会在中心附近设一个"忽略区"——这就是死区。**

死区内的移动，游戏当作没发生。

# 二、为什么默认偏大

因为手柄是量产件。

同一批次的摇杆，中心偏移量都不一样。

**厂商要保证"任何一只手柄在保修期内都不会漂"，就得把死区设得足够大。**

代价是：所有正常手柄都要为那几个偏心的让路。

**所以默认死区不是"最优值"，是"最保险值"。**

# 三、调小会怎样

**好处**：精细操作变准。

瞄准时的小幅修正、赛车时的细微方向调整，都会更跟手。

**代价**：如果你的摇杆本身有轻微偏移，漂移会显现出来。

表现是：手松开了，人物还在慢慢挪。

# 四、调大会怎样

**好处**：稳。不会漂，不会误触。

**代价**：推杆前段有一段"没反应"的空行程。

在需要精细控制的场景里很难受，比如狙击、漂移过弯。

# 五、怎么判断该往哪调

先测一下零点。

用浏览器打开 gamepad 测试页面，连上手柄，**手完全松开**。

**情况一：读数在 0 附近，跳动很小。**

→ 你的手柄状态好，死区可以调小。

**情况二：读数稳定偏在某个非零值。**

→ 你的手柄已经有偏移了。死区不能调太小，否则会漂。

**情况三：读数在 0 附近但跳动很大（±0.1 以上）。**

→ 这是信号噪声，可能需要换手柄或者修。

# 六、在哪调

三个地方，优先级从高到低：

一、游戏内设置。

大部分 FPS 和赛车游戏都有「摇杆死区」选项。这是最直接的，因为游戏自己知道怎么用它。

二、Steam Input。

Steam 的控制器配置里能设死区，而且能按游戏分别存配置。

适合游戏内没有这个选项的情况。

三、手柄官方驱动。

部分品牌（比如某些第三方手柄）有自己的软件，能改硬件层死区。

**一般不用动这一层。**

# 七、一个常见的误区

有人以为"死区调到 0 = 最灵敏"。

**不是。**

调到 0，摇杆的物理噪声会被当成输入，画面会抖。

**死区的合理值取决于你手柄的实际状态，不是越小越好。**

# 八、我的建议

**先测，再调。**

- 读数干净 → 死区调到能消除跳动的最小值
- 读数有偏移 → 死区留着，或者考虑换摇杆
- 不想折腾 → 用默认，反正不影响能不能玩

这事的收益是"手感更准"，不是"能不能玩"。

**期望值别设太高。**

你调过手柄死区吗？调完感觉明显吗？
