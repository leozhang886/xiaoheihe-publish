大版本更新完，进游戏一看，画质回到默认，键位全变回去了。

**不是你的错觉，也不是游戏针对你。**

# 一、为什么会被重置

**游戏的设置存在本地文件里，而更新可能替换掉整个配置目录。**

三种常见情况：

- 更新包直接覆盖了配置文件
- 配置格式变了（新增字段），旧文件读不进来
- 游戏换了配置文件的存放路径

第三种最坑——旧文件还在，但游戏已经不读它了。

# 二、Steam 云存档也救不了

**很多人以为开了云同步就没事。**

**但云同步管的是存档，不一定管设置。**

有些游戏把设置也放进去，有些没有。**没有的话，本地一覆盖就没了。**

# 三、提前备份什么

**三个位置，覆盖绝大多数游戏：**

- `文档\My Games\<游戏名>`
- `%LOCALAPPDATA%\<游戏名>`
- `游戏安装目录\`（有的老游戏放这儿）

**Windows 输入 `%LOCALAPPDATA%` 能直接跳过去。**

进游戏前先看一眼这三个地方有没有东西，有就整个文件夹复制一份。

# 四、更省事的办法

**如果游戏支持导出配置，就用它。**

不少游戏在设置里有「导出」/「保存配置」，导出的文件比翻目录可靠。

**不支持的话，退而求其次：改完设置后，把配置文件复制到一个固定文件夹。**

**养成习惯之后，重置了直接粘回去。**

# 五、键位单独备份

**画质可以重调，键位是真的烦。**

尤其自定义了很多键的时候，重设一遍要半小时。

**有些游戏支持键位导出，多数不支持。**

**不支持的话，改完截个图，也算有备份。**

# 六、更新前的一分钟

**三件事，一分钟能做完：**

- 复制配置文件夹
- 截图键位设置
- 记下当前的画质档位

**成本很低，省的是重调的一两个小时。**

# 七、一个例外

**有些更新故意重置设置。**

比如改了渲染管线、换了默认画质策略。

**这种情况强行用旧配置，反而可能出问题。**

**所以重置之后先别急着恢复**，看看新默认值是不是本来就合适。
