游戏画质菜单里有个「超分辨率」的选项。

**它下面可能有三个名字：DLSS、FSR、XeSS。**

三个都能开，但不是同一个东西。

# 一、它们的共同目标

都是干同一件事：

**让显卡用低分辨率渲染，再把画面放大到高分辨率。**

好处是帧数上去，画质损失比直接降分辨率小。

**但实现方式完全不同，效果差别不小。**

# 二、DLSS

**NVIDIA 独占，需要 RTX 系列显卡。**

它用显卡里的专用单元（Tensor Core）做 AI 推理。

**效果目前是三家里最好的**，尤其是低分辨率下的细节重建。

**代价是只有 N 卡能用。**

# 三、FSR

**AMD 做的，但全平台开放。**

N 卡、A 卡、Intel 都能开，甚至老显卡也支持。

**它的策略是"不依赖专用硬件"**，用通用计算做空间或时间的重建。

**效果比 DLSS 差一点，但兼容性最好。**

**用 A 卡或者老 N 卡的人，基本只有这一个选择。**

# 四、XeSS

Intel 做的。

它有两种模式：

- **用 Intel 显卡的专用单元**（效果更好）
- 用通用指令模拟（其他显卡也能跑）

兼容性介于两者之间。

# 五、怎么选

一张表说清：

| 你的显卡 | 优先选 |
|---|---|
| RTX 系列 | DLSS |
| AMD RX 系列 | FSR |
| Intel Arc | XeSS |
| 老显卡 | FSR |

**游戏支持哪个，就开哪个，按上面顺序。**

# 六、两个容易搞错的点

**第一，能开不等于该开。**

如果你本来就能跑满帧数，**超分只会让画面变糊，没有收益**。

第二，别和帧生成混。

超分是把画面放大；帧生成是插帧。两个是不同的技术，可以叠加，但作用不一样。

# 七、我的建议

**先看自己的卡，再看游戏支持什么。**

**如果三个都支持，按上表选。**

**如果你的显卡跑得动原生分辨率，就别开。**

**超分是给跑不动的机器用的，不是画质增强。**

你现在开的是哪个？
