买了 4K 165Hz 的显示器，接上只有 60Hz。

**八成不是显示器坏了，是那根线不行。**

# 一、为什么会这样

视频接口有带宽上限。

**分辨率越高、刷新率越高、色深越大，需要的带宽越多。**

**线材不达标，带宽就不够，只能降规格。**

而很多显示器**附赠的线是按最低标准配的**。

# 二、两个接口的差别

HDMI 2.1 和 **DisplayPort 2.1** 是目前的主流高带宽接口。

**同样的规格，DP 通常更宽松。**

**而且高刷新率、多屏串联这些，DP 的支持更早更稳。**

**所以能选 DP 就选 DP。**

# 三、一个常见的坑

**显示器写"支持 4K 144Hz"，不代表你随便插一根线就能跑。**

要看三件事：

- 显示器的接口版本
- 线材的版本
- 显卡输出的版本

**任何一环不达标，就降到低规格。**

# 四、怎么判断

**第一步，看显示器在跑什么。**

很多显示器按菜单键能看当前输入的分辨率和刷新率。

**第二步，看系统设置里能选到多少。**

Windows 显示设置里如果不给你选 165Hz，说明链路不支持。

第三步，换根线试。

这一步最直接。

# 五、买线怎么挑

**认准包装上写的版本，别只看"支持 4K"。**

"支持 4K"通常指 4K 60Hz，不等于 4K 高刷。

**HDMI 要选「Ultra High Speed」，DP 要选明确标 2.1 的。**

线别买太便宜的。 长距离传输对线材质量要求更高，超过 2 米尤其明显。

# 六、还有一个隐形因素

**色深和 HDR 也吃带宽。**

同样是 4K 144Hz：

- 8bit 不开 HDR，带宽需求低
- 10bit 开 HDR，带宽需求高不少

**所以你开了 HDR 之后刷新率掉了，也是这个原因。**

# 七、我的建议

**接上显示器第一件事：确认刷新率跑满了没有。**

没跑满，先换线。

**换线还不行，再看显卡输出和显示器的接口版本。**

顺序别反——很多人一上来就怀疑显卡，白折腾。

你的显示器跑满了吗？
