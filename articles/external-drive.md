内置盘满了，能不能插个外接硬盘装游戏？

**能。但有些游戏装上去跑不动。**

# 一、先分清外接的两种

- 机械硬盘（HDD）：便宜，容量大
- 移动固态（PSSD）：贵，速度快

**一种是机械硬盘（HDD）**，便宜，容量大。

**一种是移动固态（PSSD）**，贵不少，速度快。

**它们在 Steam 眼里是同一类：外部存储。**

# 二、接口决定上限

**USB 3.0 理论 5Gbps，实际大概 400MB/s 出头。**

**USB 3.2 Gen2 能到 10Gbps，实际大约 900MB/s。**

**但如果你的口是 USB 2.0，那就别想了**——那速度连老机械盘都不如。

**插之前先确认接口版本。**

# 三、哪些游戏不能放外置

**关键看游戏有没有写「必须安装到 SSD」。**

这几年越来越多游戏把这条写进最低配置。

**比如《影之刃零》就明确要求装在 SSD 上。**

**这类游戏放机械外置盘，基本进不去或者卡到不能玩。**

# 四、哪些游戏完全没问题

**老游戏、独立游戏、回合制、策略类。**

它们对随机读写要求低，机械外置盘完全够用。

**这也是外接盘最该用在哪：把一堆小体量游戏挪出去，给内置盘腾地方。**

# 五、一个实际的做法

分级存放：

- 常玩的 3A → 内置 NVMe
- 偶尔玩的中体量 → 内置 SATA SSD
- 一堆小游戏、怀旧游戏 → 外接机械盘

**这样内置盘的空间能省出一大截。**

# 六、两个坑

第一，别拔着玩。

游戏运行时拔掉外接盘，轻则崩溃，重则存档损坏。

**第二，Steam 的「移动安装文件夹」要用。**

在设置里改库位置，让它自己搬，别手动剪切文件。

**手动剪切的话，Steam 会认不出来。**

# 七、我的建议

**外接硬盘适合当仓库，不适合当主力。**

**花钱优先级应该是：内置 NVMe → 内置 SATA SSD → 外接盘。**

外接盘解决的是「放不下」，不是「跑得慢」。
