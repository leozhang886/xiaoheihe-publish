先说结论：

**大部分时候，你不需要"干净安装"。**

在驱动面板里点「清洁安装」就够了。

真正需要动 DDU 的，只有几种特定情况。

# 一、什么情况下才需要 DDU

DDU 是 Display Driver Uninstaller。

它专门把显卡驱动连残余文件一起清掉。

这几种情况值得用：

- **换显卡品牌**（NVIDIA 换 AMD，或者反过来）
- 驱动反复崩溃、黑屏、花屏
- 装了某个版本之后帧数异常，回滚也没用
- 驱动安装程序反复报错

这几种情况不需要：

- 常规升级驱动
- 同品牌换卡（比如 3060 换 4070）
- 只是帧数不理想

大多数人属于后一类。 每次升级都跑一遍 DDU 是过度操作。

# 二、DDU 是什么

工具在 GitHub 上叫 [display-drivers-uninstaller](https://github.com/Wagnard/display-drivers-uninstaller)。

★913，两天前还在更新。

免费，开源。

它会把驱动、注册表项、残留文件一起清掉。

比 Windows 自带的卸载彻底得多。

# 三、正确流程

第一步，先把新驱动下好。

这一步很多人漏掉。

用 DDU 清完之后，你大概率没网——因为网卡驱动也可能被牵连，或者你断网了。

**所以先下载好安装包，放在桌面上。**

第二步，断网。

拔网线、关 WiFi。

Windows 会自动联网装一个旧版驱动，那会干扰你。

第三步，进安全模式。

这是 DDU 的核心要求。正常模式下有些驱动文件被占用，删不干净。

路径：设置 → 系统 → 恢复 → 高级启动 → 立即重新启动。

然后依次选：疑难解答 → 高级选项 → 启动设置 → 重启 → 按 4（启用安全模式）。

第四步，运行 DDU。

- 选设备类型：GPU
- 选品牌：NVIDIA / AMD / Intel
- 点「清除并重启」

第五步，重启后装新驱动。

这时候还是断网状态，装完再联网。

# 四、几个容易出错的地方

**一，别在正常模式下跑 DDU。**

能跑，但清不干净。安全模式是硬要求。

**二，别用 DDU 的「清除并关机」。**

除非你要拔卡。选「清除并重启」。

**三，装完再联网。**

Windows Update 会偷偷装旧驱动，装完再联网能避开。

**四，有些笔记本的双显卡要分开处理。**

核显和独显都在的时候，DDU 里要确认清的是哪一个。

# 五、装新驱动的正确顺序

1. 装驱动主体
2. **重启**
3. 再装附加组件（GeForce Experience / Adrenalin 的可选部分）

**别一次装完所有东西再重启。**

出了问题你不知道是哪一个。

# 六、装完怎么验证

三个地方看：

- **设备管理器**里显卡型号对不对
- **驱动版本号**和你装的是否一致
- **跑个游戏看帧数**

如果帧数比之前还低，先别急着再折腾，**用 DDU 回退到上一个稳定版本**反而更快。

# 七、我的建议

**常规升级，就用驱动面板的「清洁安装」，别动 DDU。**

**出问题了再用。**

DDU 是手术刀，不是日常用品。

用对了能救活一台机器，用错顺序会浪费你一晚上。

你上次装驱动是什么时候？出过问题吗？
