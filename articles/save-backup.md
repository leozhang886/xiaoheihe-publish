帧数低只是难受，存档丢了是几百小时没了。

但大部分人从来没备份过。不是懒，是**不知道该备份什么**——每款游戏的存档位置都不一样，找起来就放弃了。

这篇把这件事说清楚。

# 先破除一个误会：云存档不是备份

很多人心里想的是"我有 Steam 云存档，不怕"。

**云存档解决的是"换台设备接着玩"，不是"备份"。**

它的逻辑是**同步**，不是**归档**。你在本地删掉了存档，云上那份通常也会跟着被删——因为同步是双向的，它认的是"最新状态"，不是"保留历史"。

还有个更隐蔽的坑：**云存档冲突**。

同一个游戏在两台设备上都玩过，同步的时候会弹出让你选"云端版本"还是"本地版本"。这个提示很多人看不懂就随便点，**点错就是把一边的进度覆盖掉**。

而且——**不少游戏压根不支持云存档**。买之前不看，丢了才知道。

# 存档到底在哪

这是最难的部分。常见的位置有这么几类：

- `我的文档` 下的游戏文件夹（最常见）
- `AppData` 里（隐藏目录，很多人找不到）
- 游戏安装目录里
- **Windows 注册表里**（少数老游戏，最难搞）

**每个游戏用的都不一样**，没有统一规律。

![](assets/save-locations.jpg)

所以这件事靠人肉记是不现实的。好在有人建了个数据库：[Ludusavi Manifest](https://github.com/mtkennerly/ludusavi-manifest)（★177），专门记录每款游戏的存档位置。它的数据主要来自 [PCGamingWiki](https://www.pcgamingwiki.com/)，社区维护。

# 现成的工具：别自己写脚本

我搜了一圈，这个方向有成熟工具，而且都挺活跃。

**首选 [Ludusavi](https://github.com/mtkennerly/ludusavi)**（★6,420，MIT，Rust 写的）

- 支持 **19,000 款以上**游戏的存档
- 覆盖 Steam、GOG、Epic、Heroic、Lutris 等多个平台
- **文件存档和注册表存档都能处理**——这解决了上面那个最难的情况
- 图形界面 + 命令行都有，可以定时脚本化
- **Steam Deck 上能用**，还有 Playnite 插件

其他选择：

| 工具 | ★ | 说明 |
|---|---|---|
| [Game-Save-Manager](https://github.com/dyang886/Game-Save-Manager) | 1,546 | 界面友好，国人作者 |
| [SaveState](https://github.com/Matteo842/SaveState) | 516 | 支持拖放操作，Win/Linux |
| [Game Backup Monitor](https://github.com/MikeMaximus/gbm) | 292 | 侧重自动监控和定时备份 |

# 不想装工具的话

手动也能做，就三步：

**一、去 PCGamingWiki 查你要玩的那款游戏**，搜游戏名加 "save game data location"，它会告诉你确切路径。

**二、把那个文件夹整个复制走**，存到另一个盘或者网盘。存档通常很小，几 MB 到几十 MB。

**三、记住时机**：重装系统前、换电脑前、装大型 mod 前——**这三个时间点必须做**。尤其是装 mod，很多 mod 会改存档格式，装完之后旧存档可能就读不了了。

# 最后

这件事的特点是：**平时做不做没区别，出事的时候有没有是天壤之别。**

备份的成本是十分钟，代价是不做的话可能重玩两百小时。

我自己是在丢过一次存档之后才开始定时备份的。希望你不用经历这一步。
