先说结论：

**只想录个高光发群里，系统自带的就够了。**

装 OBS 是对付直播和剪辑的，不是用来录三十秒视频的。

这篇讲清楚自带工具的边界在哪。

# 一、它是什么，怎么打开

Windows 里有个叫 Game Bar 的东西，一直装着，只是很多人没打开过。

按 **Win + G** 就出来。

不管你在玩什么，只要窗口是激活的，它都能调出来。

# 二、能做的事

**截图。** 快捷键 Win + Alt + PrtSc，存在「视频\捕获」文件夹。

**录屏。** Win + Alt + R 开始和结束。

**性能面板。** 能看 CPU、GPU、内存占用，还有当前帧数。

这个挺实用，比单独装个监控软件省事。

**后台录制（回溯）。** 这个是最被低估的。

它一直在后台录最近几十秒，按一个快捷键就能把刚才那段时间存下来。

打出一波神操作，事后按一下就有了，不用提前开录。

# 三、三个硬限制

**限制一：只能录单个应用窗口。**

切出去看桌面、看文件夹，录不到。

录桌面、录多个窗口拼一起，它做不到。

**限制二：录制有时长上限。**

长时间连续录，它不是合适工具。录播、录课程那种，得换。

**限制三：音频处理很粗。**

只有「游戏声 + 麦克风」这一路混音。

想要游戏声和麦克风分开成两条音轨，方便后期调音量，它做不到。

**对剪辑过的人，这条是硬伤。**

# 四、什么时候必须上 OBS

碰到下面任何一条，就别折腾自带的了：

- 要录桌面、录整个屏幕
- 要录超过半小时的连续内容
- 要游戏声和麦克风分开
- 要做多场景切换（游戏画面 + 摄像头 + 弹幕）
- 要直播
- 要精细控制码率、编码器、分辨率

那就是 [OBS Studio](https://github.com/obsproject/obs-studio)（★77,844，10 月还在更新）。

免费、开源、功能全。代价是**第一次配置要花点时间**，不懂参数容易配出糊的画面。

# 五、还有个国产的轻量选择

如果嫌 OBS 重，可以看看 [eSearch](https://github.com/xushengfeng/eSearch)（★7,344，10 月还在更新）。

它不只是录屏，还带截图、离线 OCR、贴图、屏幕翻译。

**适合的场景**：录一小段、顺手截图、把屏幕上的英文 OCR 出来。

**不适合的**：专业录制和多轨音频。

# 六、怎么选，一句话

- **录几十秒发群里** → 自带
- **录桌面 / 长时间 / 要分轨** → OBS
- **录+截图+OCR 混着用** → eSearch

别为了录三十秒去装一个要配半小时的软件。

# 七、两个容易被忽略的点

**一、录之前先看硬盘。**

1080p 录一小时大概几个 G，录 4K 更多。别录到一半卡了。

**二、性能面板和录制会占资源。**

录 4K 的时候帧数会掉一点，这很正常。要测真实帧数就先关录制。

你平时录游戏用什么？有没有为了录一段折腾过半天的？
