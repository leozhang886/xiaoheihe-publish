显卡超频，能多挤出的性能一般只有 **5% 到 10%**。

**代价是温度上去、风扇转速上去、稳定性下来。**

有个收益更大、风险更小的做法：降压超频。

# 一、为什么降压能更快

先说一个反直觉的事实。

**显卡出厂时的电压，是按“最差的那颗芯片”留的余量。**

你的卡大概率不需要那么高的电压。

**电压降下来，功耗和温度跟着降，于是它能更久地待在最高频率上。**

**结果是：温度更低，帧数反而可能更高。**

# 二、和超频的区别

| | 普通超频 | 降压超频 |
|---|---|---|
| 改什么 | 拉高频率 | 调低电压，频率可能降一点 |
| 温度 | 上升 | 下降 |
| 噪音 | 变大 | 变小 |
| 帧数 | +5~10% | **持平或略升** |
| 稳定性 | 可能变差 | 一般更稳 |

**表格里最关键的是最后一行。**

高温会触发降频，降频会让帧数波动——**超频带来的收益经常被温度吃掉。**

# 三、什么情况值得做

值得：

- 你的卡温度高、风扇响
- 房间夏天热
- 你在意噪音

**不值得：**

- 显卡温度本来就很好
- 还在保修期，不想折腾
- 你不确定怎么回滚

# 四、风险要说清

**降压调过头，会不稳定。**

表现是：花屏、驱动崩溃、游戏闪退。

**不是硬件坏了**，把设置改回去就行。

**但前提是你知道怎么改回去。**

所以动手之前：**记下原始设置，或者准备好重装驱动的方案。**

# 五、我不给具体参数

**因为每张卡的体质不一样。**

同一型号的两张卡，稳定的电压点可能差一截。

**抄别人的参数，有大概率不稳，或者很保守白折腾。**

思路给你，具体数值自己试。

# 六、一句实话

**如果你玩得挺舒服，就别改。**

调这些的收益，大多数人是感觉不到的。

**真正能明显改善体验的顺序是：**

- 先把画质设置调对
- 再考虑散热（机箱风道、清灰）
- 最后才轮到电压和频率

**顺序反了，就是在优化一个不是瓶颈的东西。**
