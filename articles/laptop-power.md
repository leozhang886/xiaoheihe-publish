同一台游戏本，同一个游戏。

**插着电跑 120 帧，拔掉电源掉到 40。**

不是你电脑坏了，是它在按规则办事。

# 一、为什么拔电就掉帧

三个限制同时生效。

**第一，电池供不起那么大的功率。**

一块游戏本的电池，输出能力通常在 100 瓦上下。

而一张高性能显卡满载单独就要 100 瓦以上。

整机功耗是电池给不出来的。

**第二，厂商主动降频。**

拔电之后，大部分游戏本会自动切到「节能」或者「平衡」模式。

CPU 和显卡的功耗墙直接砍半。

**第三，这是一个设计选择。**

厂商知道你不会用电池打游戏——**打一局 3A，电池撑不到一小时。**

所以它们干脆不为这个场景优化。

# 二、具体掉多少

不同类型差别很大。

- **轻薄的创作本**：插电 100%，拔电可能只剩 40%
- **游戏本**：插电 100%，拔电大约 50-60%
- **桌面替代型（很重的那种）**：拔电可能只剩 30%

越往上堆性能的机器，掉得越狠。

因为它本来就是按「有插座」设计的。

# 三、怎么确认自己是不是这个情况

最简单的办法：

**打开游戏，看帧数，然后拔掉电源。**

如果帧数断崖式下跌，就是这个原因，不用再折腾驱动和设置了。

**顺便说，插电时也要看好模式。**

很多游戏本默认不是「性能模式」，要手动切。

**插着电但用的是平衡模式，同样跑不满。**

# 四、一个容易误解的地方

有人会想：「那我把电池模式改成就高性能不就行了？」

**不行。**

Windows 的电源计划管不了硬件层面的功率墙。

**厂商的 EC（嵌入式控制器）会直接限制。**

你在系统里怎么设置，都越不过那道墙。

# 五、对使用习惯的影响

**第一，打游戏必须插电。**

这不是建议，是硬要求。

**第二，别长期插电玩游戏还担心电池。**

现代笔记本大部分有「电池保护」功能，插电时会限制充电上限（比如 60% 或 80%）。

**开了这个，长期插电对电池反而更友好。**

第三，出门前算好。

如果要在外面玩游戏，认清现实——**能玩，但别指望插电的性能**。

# 六、一句实话

这不是游戏本的质量问题。

游戏本的定义就是「可以搬动的台式机」。

**搬动指的是换地方，不是换电源状态。**

理解了这一点，很多"为什么我电脑这么卡"的疑问就没了。

你打游戏会插电吗？掉过帧没？
