游戏本的控制中心里通常有几个模式：安静、平衡、性能、狂暴。

**很多人以为"狂暴"是解锁了隐藏性能。**

**其实它改的是两件事：功耗墙和风扇曲线。**

# 一、功耗墙是什么

CPU 和显卡都有功率上限。

**厂商会设一道墙，超过这个功率就降频。**

**功耗墙高一点，性能就多一点，温度也高一点。**

**"性能模式"做的第一件事，就是把墙抬高。**

# 二、风扇曲线是什么

墙抬高之后会热。

**所以第二件事是让风扇转得更快、更早介入。**

**这就解释了为什么开性能模式噪音会明显变大。**

**它不是"顺便变吵"，是必须变吵。**

# 三、还有一个：温度墙

比功耗墙更硬的一道。

温度到某个值，不管功耗墙多高，都会强制降频。

**所以会出现这种情况：**

**开了性能模式，帧数反而更不稳。**

因为功率上去了、温度也上去了，撞到温度墙就开始反复降频。

**这是很多人觉得"性能模式没用"的真实原因。**

# 四、什么样的机器适合开

散热好的机器——开性能模式有明显收益。

散热一般的机器——开了可能只是更吵更热，帧数没涨。

薄的机器——基本别指望，物理上就散不掉那些热量。

# 五、怎么判断自己属于哪种

方法很简单。

同一个游戏，同一个场景：

- 开平衡模式跑一遍，记下帧数和温度
- 开性能模式跑一遍，再记一次

**如果性能模式帧数涨了、温度也可控，那开着。**

**如果温度冲到很高、帧数波动更大，那就用平衡模式。**

# 六、一个更实际的建议

三件事：垫高、清灰、别放床上。

**比起切模式，先把机器垫高、清灰、别放在床上用。**

**这三件事对温度的影响，经常比换模式更大。**

尤其垫高——进风口被堵住，什么模式都白搭。

# 七、我的建议

**性能模式不是"隐藏开关"，是"用噪音换性能"。**

**你能接受那个噪音，且机器散热跟得上，就开。**

**不行的话，平衡模式往往更稳。**
