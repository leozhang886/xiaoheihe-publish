对，标题没骗你。

这篇帖子的标题、正文、配图、排版、关联社区——全是 AI 干的。我做的事只有两件：告诉它"写一篇怎么用你发小黑盒的"，以及它写完之后说一句"可以"。

我不是来推销工具的。是因为我一直在小黑盒发东西，被同一件事卡了很久，最后干脆让 AI 把这条路走通了。中间踩的坑，可能对你也有用。

# 先说卡在哪

我习惯在本地用 Markdown 写稿，写完再粘进小黑盒。

问题是：**粘过去格式就没了。**

空格、换行、层级标记全部被吃掉。标题变成普通段落，加粗没了，表格直接塌成一坨。我得对着原稿，在黑盒编辑器里一个字一个字把格式重敲一遍。

一篇 1000 字的稿子，排版能吃掉半小时。

# 为什么会这样

查了一下，小黑盒的编辑器用的是 **ProseMirror**——一种结构化的富文本编辑器。

它不接受"源代码"，只接受"结构"。你直接粘 Markdown 源码，等于给它丢了一堆它读不懂的符号，出于安全过滤（防注入），这些符号会被清掉。

这机制本身没毛病，只是对习惯手写 Markdown 的人不太友好。

# 三个坑，写文的人都能用上

## 一、小黑盒的"一级标题"其实是 h2

这个最坑。

工具栏里点「一级标题」，生成的标签是 `<h2>`，**不是 `<h1>`**。二级标题是 `<h3>`。

所以从 Markdown 转过来时，`#` 必须映射成 `<h2>`，`##` 映射成 `<h3>`。

你要是按习惯用了 `<h1>`，它会被**降级成普通段落**——标题全废。

## 二、表格和代码块它不支持，只能转图

小黑盒的文章里没有表格语法。你插进去的表格会塌成一行纯文字，所有列糊在一起，完全没法看。

代码块同理。

想放表格，唯一解是**截图成图片**再插进来。

## 三、"粘贴事件"比模拟打字强太多

如果要在编辑器里自动填内容，别一个字一个字模拟键盘。

正确做法是构造一个带 `text/html` 的粘贴事件，直接派发进编辑器。这样标题、加粗、引用、有序无序列表**全都能保留**，而且一瞬间就填完。

这条路走通之后，一篇 1000 字带 3 张图的稿子，从打开创作页到填完大概 1 分钟。

# 顺便一个发现：封面到底是哪张图

网页版的文章编辑器里，**没有"设置封面"这个选项**。

`发布设置` 里只有权限设置、创作计划、内容声明。

那信息流里显示的那张图是哪来的？——**就是你正文里的第一张图。**

所以第一张图别乱放。想让人点进来，最好看的那张必须放在最前面。我这次是把封面排在正文最顶上的。

# 有件事得说清楚：它不能全自动

就我查到的情况，**小黑盒没有对外的文章发布接口**。

所有第三方工具能做到的上限，都是"把内容塞进编辑器"，后面还是得有人点发布。

图片也一样，得走小黑盒自己的上传弹窗，让它转存到自己的 CDN，不能用外链直接引用。

我原本保留最后一步手动点，理由很实在：**发布是不可逆的**，发出去就是公开内容，代表我的账号。

不过这一篇，我让它自己点了。它做到了。

# 最后

我不觉得 AI 写的稿子能替代人。

它不知道你昨天晚上被哪个 BOSS 卡了两小时，也不知道你为什么突然想推荐一款老游戏。**"为什么想说"这件事，还是得你自己有。**

它能做的是把"想说的东西"高效地变成"能发出去的排版"。省下来的时间，够你多玩两关。

你们平时写小黑盒是用什么排版的？有没有更省事的办法，评论区教教我。
