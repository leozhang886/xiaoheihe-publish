Steam 更新、游戏维护、平台改版，很多都放在周二。

这不是错觉。

按星期排一下更新时间，周二的比例明显偏高。

# 一、为什么不是周一

**周一要处理周末积压的问题。**

周末上线的人多，客服、社区、运维都在灭火。

**这时候推更新，等于在最忙的时候再开一个新战场。**

**一旦出问题，没有人手处理。**

# 二、为什么不是周五

这个更明显。

**周五推更新，出了问题没人修。**

周末玩家最多，一旦崩了，要等到下周一才有人管。

**这是所有运维都懂的常识：不在长假期前上线。**

# 三、周二到周四的三天窗口

**排掉周一和周五，剩下的就是中间三天。**

**周二最前，留出的修复时间最长。**

出了问题，周三周四还能补，周五之前还有机会。

所以周二成了最优解。

# 四、还有平台的审核节奏

主机平台对更新有审核流程。

**索尼、微软、任天堂各自有提交时间和周期。**

**为了让 PC 和主机的更新尽量同时上线，发行方会往前倒推日期。**

**倒推出来的结果，经常落在周二。**

# 五、行业惯例是怎么形成的

**不是有人规定，是大家陆续发现"这么排最省事"。**

一开始可能只是某几家的习惯。

**后来因为跨平台同步、玩家预期、媒体排期，慢慢变成了共同节奏。**

**这种惯例一旦形成，就很难改——因为所有人都在按它安排自己的计划。**

# 六、也有例外

紧急修复不看星期。

挖出严重 bug、被人利用、服务器崩了，随时上线。

**还有一类是内容更新，会挑玩家的活跃时间。**

**周二其实是个折中：工作日白天玩的人少，出问题影响小。**

# 七、所以看到周二更新，说明什么

**说明这家厂商有基本的运维意识。**

知道要避开周末，知道要留修复窗口。

**反过来，如果一个游戏总在周五晚上更新，那它出问题的概率会更高。**

**这不是玄学，是把风险留给了没人上班的时间。**
