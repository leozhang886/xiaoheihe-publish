万代南梦宫清算了一家加拿大工作室。

这类消息这两年越来越密。

**值得问的不是"哪家又关了"，是"为什么关了还要买"。**

# 一、收购的逻辑

大厂买工作室，通常为三样东西：

- 一个能打的 IP
- 一支现成的团队
- 一条已经跑通的产品线

**买的时候算的是"这个团队未来能出几款游戏"。**

**问题是，这笔账在后面几年经常算不平。**

# 二、为什么算不平

**第一，收购价格里包含了"未来预期"。**

买的时候溢价付了，后面每一款游戏都得先把这个溢价赚回来。

**第二，团队规模在收购后通常变大。**

人多了，单款游戏的开发成本就上去了。

第三，项目周期变长。

现在一款 3A 做四五年是常态，这四五年里没有收入，全是支出。

**三条叠在一起，一个项目失败就可能把整个工作室拖垮。**

# 三、关掉比留着划算

这是最反直觉的一点。

**留着，要继续付工资、付房租、付引擎授权费。**

关掉，成本立刻归零。

**从财务报表看，关掉一家不赚钱的工作室，是最快的止血方式。**

**至于那个团队做过什么、有多少人——报表上不体现。**

# 四、这波潮的共同点

**近两年关停的工作室，很多是同一类：**

- 被收购三到五年
- 只出过一款作品，或者一款都没出
- 手上的项目被取消过一次以上

这个时间点不是巧合。

**收购时的承诺期大概就是三到五年，到点了交不出东西，就得走流程。**

# 五、对玩家的影响

**短期看是"某个系列没续作了"。**

**长期看是"能做大项目的团队在变少"。**

一家工作室关掉，那些人会散到各处，**但重新组起来做出同样的东西，需要好几年。**

**行业的人才不会消失，但组织能力会消失。**

# 六、一个不太好听的事实

**大部分被关的工作室，在被收购那天就已经注定了一部分结局。**

因为收购方买的往往是"产品"，不是"团队"。

**产品做完了，团队的价值就下降了。**

**这不是某一家的道德问题，是这套资本结构的必然结果。**
