第二期。还是每周扒一遍 GitHub 榜单，挑 5 个跟游戏沾边、玩家真能用上的项目。

**这周的主题跟上周不一样。** 上周是模拟器扎堆，这周换成另一批——全是"官方不做，社区自己做"的项目。

有把二十多年前的老游戏搬回现代系统的，有把主机游戏重编译成 PC 原生程序的，也有干脆自己做引擎、自己做游戏的。

# 一、DevilutionX：把《暗黑破坏神1》搬回现代系统

★9,869 · 本周小幅增长 · **今天还在提交**

**它是什么**：《暗黑破坏神1》的现代系统移植版。原版 1996 年发售，现在的 Windows 上跑起来一堆问题，暴雪也没打算管。

DevilutionX 把游戏重写了一遍，能在 Windows / macOS / Linux 上原生跑，还修了原版的 bug、加了高分辨率支持和手柄操作。

**为什么值得看**：暗黑1 是那个类型的起点，但二十多年前的画面和操作确实劝退。这个版本解决了"想玩但装不上"的问题。

**提醒**：它需要你**自己有原版游戏的文件**（GOG 上有卖）。项目本身不含游戏内容。

# 二、PS2Recomp：把 PS2 游戏变成 PC 原生程序

★3,519 · 本周 +166 · 2 天前更新 · GPL-3.0

**它是什么**：PS2 的**静态重编译器**。

注意它和模拟器不是一回事。模拟器是"在 PC 上假装自己是一台 PS2"，一边翻译一边运行，开销大。**重编译是提前把游戏代码翻译成 PC 能直接跑的机器码**，跑起来就是原生程序。

**为什么值得看**：这条路如果走通，老游戏的性能表现会比模拟器好得多。同类的还有做 PS3 的 `ps3recomp`、做 Xbox 360 的 `rexglue`——**这个方向今年明显在爆发**。

**提醒**：这是开发工具，不是给普通玩家开箱即用的成品。它面向的是想参与移植的人。

# 三、bevy：Rust 写的开源游戏引擎

★49,045 · 本周 +360 · 今天还在提交 · Apache-2.0

**它是什么**：一个用 Rust 写的**数据驱动游戏引擎**，是 GitHub 上星最多的开源游戏引擎之一。

**为什么值得看**：如果你是写代码的，这是现在最值得关注的引擎之一。Rust 的内存安全让你少踩很多坑，ECS 架构写起来也清爽。

**提醒**：它**不适合所有人**。想做游戏又不想写代码的，去看虚幻或者 Unity。bevy 面向的是愿意写代码的人。

# 四、Beyond All Reason：免费开源的大型 RTS

★4,303 · 本周 +39 · 今天还在提交

**它是什么**：一个**完全免费的开源即时战略游戏**，跑在开源引擎 Recoil 上。官网直接可以下载。

**为什么值得看**：这一类"造基地、拉兵线、打大规模团战"的 RTS，商业市场上基本没了。BAR 在精神上是《横扫千军》《最高指挥官》那一脉的延续，而且**它是免费的，没有内购**。

**提醒**：上手不轻松。RTS 的老问题——操作门槛和快捷键量——它一个不少。

# 五、koharu：用 AI 翻译日文漫画，Rust 写的

★6,322 · 本周 +557 · 今天还在提交 · Apache-2.0

**它是什么**：机器学习驱动的**漫画翻译器**，用 Rust 写的。

**为什么值得看**：日语游戏和漫画的汉化，长期靠民间汉化组，等更新是常态。这类工具把"能看懂"这件事的门槛降下来了。

**提醒**：机器翻译对**剧情向、台词绕的**作品效果有限，人名和双关最容易翻车。当辅助可以，当成品不行。

# 本周观察

把这五个放一起看，有个共同点：**它们补的都是官方留下的空位。**

![](assets/gh-weekly/week2-board.jpg)

老游戏官方不移植，玩家自己写移植；主机的老游戏官方不复刻，玩家自己写重编译器；商业 RTS 没人做了，社区自己做一个免费的；日文作品没有官方中文，玩家自己训练翻译。

**这不是情怀，是需求没被满足。**

对比一下隔壁榜上那个一周涨 2.5 万星的 PS5 移植工具——同一股力量的另一种表现。我上一期就说过这类工具我不推荐，原因还是那个：性质和模拟器不一样。

# 最后

这些项目的共同风险是**寿命**。靠爱发电的东西，作者哪天不干了就停更。

所以用之前看一眼**最后提交时间**——这一条对开源项目比 star 数重要得多。
