按 F12 截图，按完就忘。

**过几天想找那张图，翻遍电脑也没有。**

问题是——你不止一套截图机制。

# 一、你电脑上至少有四套

**一，Steam 自带。**

默认 F12。存在 Steam 的 userdata 目录里。

**二，NVIDIA 的。**

GeForce Experience 或新版 App，默认 Alt+F1。

**三，Windows 的。**

Xbox Game Bar，默认 Win+Alt+PrtScn。

**四，显卡驱动或者第三方软件。**

比如 OBS、ShareX、各种录屏工具。

**四套各存各的，互不相通。**

# 二、它们分别存在哪

Steam：

路径在 Steam 目录下的 userdata 里。

然后用你的数字 ID、760、remote、游戏 ID 一层层往下点。

**最后那个 screenshots 文件夹就是。**

NVIDIA：

在 `视频` 或者 `图片` 文件夹下的 `NVIDIA` 目录。

**Windows Game Bar**：

`视频\捕获` 文件夹。

路径会随版本变。

最靠谱的找法：在各自的软件里点"打开文件夹"，让它自己带你去。

# 三、怎么统一

**第一，把三个都改成同一个文件夹。**

Steam 在设置里能改截图目录。

NVIDIA 和 Game Bar 也能改。

**第二，只留一套常用的。**

如果主要用 Steam 玩，就只用 Steam 截图。

别同时开三套的快捷键——会互相覆盖。

# 四、一个容易忽略的问题

**F12 在很多游戏里是游戏内的按键。**

- 有些游戏 F12 是快速存档
- 有些是切换视角

**你按一下，游戏存了档，Steam 也截了图。**

改了 Steam 的截图键之后，检查一下游戏里有没有冲突。

# 五、录屏更麻烦

截图还只是图片，录屏是几个 G 的文件。

**几个工具的录屏都存在自己目录里，而且默认不压缩。**

**如果不定期清理，硬盘会被悄悄吃掉。**

建议：

- 录屏目录单独设一个盘
- 定期删
- 或者用「即时重放」，只保留最近几分钟

# 六、一个实际的整理习惯

**按游戏分文件夹，按日期命名。**

截图名字里带上游戏名和日期，以后搜索就能找到。

**这事做起来花不了多少时间，但找图的时候能省半小时。**

# 七、这事花不了几分钟

**截图找不到，不是你的问题。**

是这几套机制本来就没打算配合。

**把它们统一到一个目录，问题就解决大半。**

你截图一般用什么？找得到吗？
