前几天出了件怪事。

**新游戏上线，厂商建议玩家把显卡驱动退回旧版本。**

新游戏配旧驱动，听着就别扭。

**但搞懂驱动在干什么，这事就不奇怪了。**

# 一、驱动里装了什么

除了让显卡能跑，驱动里还有一大堆针对具体游戏的配置。

业内叫 profile。

**它告诉显卡：这个游戏该怎么处理。**

- 开不开某种抗锯齿
- 阴影怎么算
- 显存的分配策略
- 某些已知 bug 怎么绕过去

**这些参数是厂商一个个游戏调出来的。**

# 二、为什么新驱动可能更慢

新驱动主要做两件事：**加新游戏的 profile，改老游戏的**。

问题出在"改老的"这句。

一次改动可能让十个游戏变快，也可能让某一个变慢。

**而且这个变慢，往往在上线后才被发现。**

因为测试覆盖不了所有游戏的所有场景。

**所以"新驱动"和"更快"不是等号关系。**

# 三、着色器编译是个大头

这几年多了件事：着色器预编译。

游戏第一次启动时会编译一堆着色器，缓存起来。

**驱动一更新，缓存可能失效，要重新编译。**

表现就是：**更新完驱动，头几局特别卡。**

**这跟"驱动有 bug"是两回事，等它编译完就好。**

# 四、什么时候该更新

我的判断标准：

该更新：

- 你要玩的新游戏在更新说明里被点名了
- 你遇到了明确的兼容问题
- 你换显卡了

可以等等：

- 一切都正常，没毛病
- 更新说明里全是你不玩的游戏

别更新：

- 你正在打排名或者做长期项目
- 更新说明没提你在玩的游戏，但你手痒

# 五、怎么退回

两个办法。

**一，驱动面板里的"回滚"，如果有。**

**二，用 DDU 清干净再装旧版**（步骤多，但最彻底）。

**退之前先做一件事：把当前版本号记下来。**

不然回不去了。

# 六、一个更大的问题

**现在玩 PC 游戏，越来越像在维护一套系统。**

查驱动、查补丁、查已知问题、查自己配置在哪个档。

**这不是玩家选的，是技术复杂度堆出来的。**

光追、超分、帧生成，每一样都要驱动配合。

**好处是画面越来越好，代价是"开箱即玩"越来越远。**

# 七、我的建议

**如果你现在玩得挺好，别动驱动。**

这条能省掉很多麻烦。

**只有在遇到具体问题，或者新游戏点名要新驱动时，再更新。**

"有更新就装"是个坏习惯——手机可以，显卡不行。

你会随手更新显卡驱动吗？
