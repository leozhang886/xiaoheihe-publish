幻萌网络发布了讣告。

**《战舰少女 R》主创铃兰离世，终年 40 岁。**

公司暂停更新致哀，官网和官博换成了黑白。

# 一、作品比名字更响

很多人对“铃兰”这个名字不熟，但知道《战舰少女 R》。

**2015 年前后，它是国内二次元手游里一个很有辨识度的存在。**

舰娘题材、纸片人、拟人化的军舰，那几年这个方向刚起来。

**它不算最赚钱的那批，但在圈子里有位置。**

# 二、那批作品的意义

我想到的是另一件事。

**2014 到 2017 年，是国内二次元手游从零到有的几年。**

那一批作品不成熟，有 bug，运营也有过争议。

**但它们定下了后来很多东西的默认样子：**

- 卡池和保底该怎么设计
- 活动和复刻的节奏
- 玩家社区怎么组织

**这些现在看起来理所当然，当时是第一批人摸索出来的。**

# 三、40 岁

这个数字让我停了一下。

**做游戏这一行，40 岁正是一个人的中段。**

尤其是主创这种位置——前面有十年经验，后面还有十年能做事。

**这个年纪离开，是行业里实实在在的损失。**

# 四、我不写的东西

有几件事我特意没写：

- 具体病因
- 公司内部的经营状况
- 玩家之间关于版权和运营的旧争议

**这些在讣告面前都不合适。**

**一个人的离开，不该被拿来复盘商业得失。**

# 五、能留下的

一个作品能活多久，和它有多成功不完全是一回事。

**有些游戏当年流水很高，现在没人提。**

**有些游戏不算爆款，但十年后还有人记得它在哪个界面点了什么按钮。**

《战舰少女 R》属于后一种。

**这大概就是做游戏的人最想要的东西。**

# 六、一句私人的话

我不玩这款游戏。

**但我知道它对某些人是“第一个充钱的游戏”。**

那种记忆很难被替代。

**一路走好。**
