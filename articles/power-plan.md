网上到处说「把电源计划改成高性能，帧数能涨」。

**改了之后发现没变化。**

**没变化是正常的——因为你改的那一层，管不到真正限制性能的地方。**

# 一、三层限制

想让笔记本跑满性能，要过三道关：

- 操作系统层：电源计划
- 厂商固件层：性能模式（EC 控制）
- 硬件层：功耗墙、温度墙

**优先级是从下往上的。**

**下面那层不放，上面怎么改都没用。**

# 二、电源计划到底管什么

它管的是 **CPU 的调度策略和降频行为**。

- 允许 CPU 降到多低的频率
- 空闲时多久降频
- 该不该用睿频

**它管不到显卡的功耗墙，也越不过厂商的固件限制。**

**所以对游戏帧数的影响，通常很小。**

# 三、什么情况改了有用

台式机——有一点用，但也不大。

老笔记本——作用更明显，因为老机器的调度策略比较保守。

新游戏本——基本没用，因为厂商的 EC 已经把功率管死了。

# 四、那该改什么

顺序反过来：

- **先切厂商的性能模式**（这一步收益最大）
- 再确保插着电
- **最后才轮到电源计划**

**大多数人把顺序搞反了。**

# 五、笔记本还有个「卓越性能」

Windows 有个隐藏的「卓越性能」计划，要命令行才能开出来。

**它主要改的是延迟敏感度，不是功率上限。**

**对游戏帧数的影响，一般也就个位数百分比。**

别指望它救场。

# 六、一个更实在的检查

**打游戏时打开任务管理器，看两个数：**

- CPU 频率：是不是明显低于标称
- GPU 占用：是不是长期 99%

**如果 GPU 一直是 99%，那瓶颈在显卡，改电源计划毫无意义。**

**如果 CPU 频率被压在很低，才值得去查功率设置。**

# 七、我的建议

**别把时间花在电源计划上。**

**先确认插电、再切性能模式、最后看散热。**

**这三件事的影响，比电源计划大一个量级。**

你改过电源计划吗？有效果吗？
