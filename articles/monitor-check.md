先说最重要的一条：

验货有时间窗口。

拆箱七天到十五天内（看商家政策），发现问题可以退换。

过了这个窗口，坏点漏光就都成你的了。

所以别急着装机，先花二十分钟验一遍。

# 一、坏点：全屏纯色看

坏点分两种：

- 死点：一直是黑的，什么颜色都不亮
- 亮点：一直是某个颜色，关不掉

测法：把屏幕切到全屏纯色，依次看黑、白、红、绿、蓝。

每个颜色下扫一遍全屏，找颜色不对的像素点。

**手机拍一张全白和全黑，放大看，比肉眼靠得住。**

坏点的行业容忍度不一样。有的品牌承诺「无亮点」，有的允许三个以内。

**买之前看清楚页面上怎么写的。**

# 二、漏光：全黑看四角

把房间灯关掉，屏幕切到全黑。

如果四边或四角有一片发白、发亮，那就是漏光。

**注意区分**：轻微的边缘发白是 IPS 的通病，几乎每块屏都有。

**真正不合格的是那种一块一块的亮斑**，像打了手电筒。

判断标准：正常使用（看电影、玩游戏）时如果你能明显看到，那就是问题了。

# 三、均匀度：白底看有没有色块

切到全白，看整块屏幕是不是同一个白。

有的屏中间亮、四角暗；有的某一角偏黄或偏红。

**这个在纯色文档、网页上最容易看出来。**

均匀度问题通常不给退，因为不算故障。但你可以据此判断这块屏的素质。

# 四、刷新率：别看参数，看实际

标称 165Hz，实际跑没跑满，得自己确认。

两个地方查：

**一、显示器自己的 OSD 菜单。**

很多型号能显示当前输入的刷新率。如果显示的是 165Hz，说明跑满了。

**二、系统的显示设置。**

Windows 里要手动选，有些系统默认给你 60Hz。

**买了 165Hz 的屏，用着 60Hz，这是最常见的浪费。**

# 五、分辨率和色深

同样容易被坑。

分辨率：4K 屏如果线材不够，可能只跑 2K。

色深：标称 10bit 的屏，需要开对模式才能跑到。有些要在驱动面板里改。

**这两项在显卡驱动面板里都能确认。**

# 六、还有一个容易被忽略的：坏点之外的外观

拆箱第一件事，先别通电。

**看屏幕表面有没有划痕、边框有没有磕碰、支架有没有变形。**

有的话直接拍照找客服，别通电。

**通电之后就说不清是运输问题还是你用出来的了。**

# 七、证据要留好

所有问题都要拍照或录像。

拍的时候注意：

- **和显示器序列号同框**（证明是这台）
- **拍到问题所在的位置**
- 用全屏纯色背景

客服认证据，不认描述。

# 八、工具这块说实话

我搜了一圈 GitHub，这个方向**没什么高星工具**。

最高的是一个叫 [screen-test](https://github.com/jaywcjlove/screen-test) 的项目，也只有十颗星。

还有 [DefectPX](https://github.com/TheHelloWorldWriter/DefectPX)，专门查坏点，六颗星。

**能用，但算不上成熟工具。**

其实你也不需要工具——**把壁纸换成纯色，全屏，就是最好的测试。**

这可能是唯一一个「不需要装软件」的硬件检测项目。

# 九、二十分钟的流程

按这个顺序走一遍：

- 关灯，全黑，看漏光
- 全白，看坏点和均匀度
- 红绿蓝各看一遍
- OSD 确认刷新率跑满
- 驱动面板确认分辨率和色深
- 有问题立刻拍照存证

**发现问题当天就联系客服**，别拖。

你买显示器验过货吗？有没有踩过坑？
