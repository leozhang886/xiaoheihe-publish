任天堂推送了 Switch 的新固件。

**官方说明通常只有一句「提升系统稳定性」。**

**但每次更新之后，社区都会自己测出改了些什么。**

# 一、官方说明为什么这么简

**因为主机固件是封闭系统。**

厂商不公布细节是常态，**一是避免被逆向，二是避免承诺。**

**所以「提升稳定性」这句话，什么信息量都没有。**

# 二、社区会查什么

通常这几项：

- 系统版本号变化
- 设置菜单里有没有新增条目
- 报错代码有没有变化
- 已知漏洞有没有被修

**最后一项最关键**——如果修了某个漏洞，破解相关的工具会失效。

# 三、对普通玩家意味着什么

**大部分时候，什么都不意味着。**

**没有新功能，没有界面变化，玩起来一模一样。**

**这类更新主要是后台修补。**

# 四、要不要立刻更新

看情况。

**如果玩联机，建议更新** —— 有些游戏会要求最新固件才能联网。

**如果不联机，等两天再看社区反馈更稳。**

**固件更新偶尔会带来兼容问题，虽然概率不高。**

# 五、一个现实问题

**Switch 的固件更新不可逆。**

**升上去就降不回来。**

**所以"等一等"这个策略，在主机上比在 PC 上更有价值。**

# 六、我的建议

**没有明确的新功能说明，就不着急。**

**除非你要联机，或者遇到了具体问题。**

**「提升稳定性」不值得你第一时间点更新。**
