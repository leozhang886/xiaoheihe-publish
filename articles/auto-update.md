打游戏突然卡一下，网络延迟暴涨。

**不一定是服务器的问题，可能你正在后台下东西。**

# 一、默认设置有多激进

**Steam、Epic、战网默认都会自动更新。**

而且**大多数人不设限速。**

结果就是：你开游戏的时候，它在满速下载。

**表现是延迟飙升、掉包、队友听你说话一卡一卡。**

# 二、Steam 该怎么设

设置 → 下载：

- **「仅在我启动游戏时允许下载」** —— 打开，最省心
- 「限制下载速度」 —— 按你的带宽设，留出余量
- 「下载时段」 —— 可以设成凌晨

第一条最关键。

开了它，你玩游戏的时候 Steam 就不会抢带宽。

# 三、Epic 和战网

**Epic：设置 → 节流下载**，可以设带宽上限和时段。

**战网：设置 → 下载 → 网络带宽**，同样能限速。

**三个平台各管各的，得分别设。**

# 四、还有个更隐蔽的

**Windows 更新。**

它会在后台下载，而且**默认允许「传递优化」——也就是把你的带宽共享出去给别人。**

**设置 → Windows 更新 → 高级选项 → 传递优化**，可以关掉。

**这条很多人不知道，但确实在吃带宽。**

# 五、怎么确认是不是这个原因

**打游戏卡的时候，看一眼任务管理器。**

- **磁盘占用 100%** → 在写入，可能是游戏更新
- 网络占用满 → 在下载
- **CPU 占用很低但卡** → 更可能是网络问题

**这一步能直接把「是电脑的事」和「是网络的事」分开。**

# 六、我的建议

**三件事，五分钟能做完：**

- Steam 开「仅启动游戏时下载」
- Epic 和战网设带宽上限
- 关掉 Windows 的传递优化

**做完之后，因后台下载导致的卡顿基本就没了。**
