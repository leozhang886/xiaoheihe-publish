打团队游戏时被说"你麦有问题"。

**大部分情况下，问题不在麦克风，在设置。**

这篇给一套能自己查的流程。

# 一、先分清是哪种"听不清"

症状不同，原因完全不同。

- **声音太小** → 增益或者输入音量
- **全是杂音** → 噪声抑制没开，或者风扇对着麦
- **声音断续** → 网络问题，不是麦克风
- **有回音** → 扬声器外放，声音被麦收进去了

**先确定是哪一种，再动手改。**

# 二、声音太小：先看系统增益

Windows 里有两个音量：

**一个是系统里的「输入音量」，一个是设备属性里的「麦克风加强」。**

第二个经常被漏掉。

**位置**：声音设置 → 输入 → 设备属性 → 级别。

**先调「输入音量」到 100%，如果还小，再加「麦克风加强」。**

加强别开太大，会一起放大底噪。

# 三、全是杂音：开噪声抑制

现在大部分语音软件都有这个选项。

- Discord：语音设置里的「噪声抑制」
- 游戏内语音：多数有类似开关

**开它之前，先做一件事：把风扇、空调、机械键盘挪远。**

软件抑制是有代价的——**它会把你的声音也削掉一部分**。

物理上解决掉源头更好。

# 四、声音断续：这不是麦的事

声音断续几乎都是网络。

**判断方法**：打字正常但语音断续，或者语音断续但游戏不卡。

**这时该看去哪**：

- 语音服务器在境外的话，走加速器
- 用 Wi-Fi 的话，换有线试试
- 上行带宽被别人占了（比如家里有人在传文件）

# 五、有回音：根本原因是外放

队友听到自己的声音回来了。

**因为你用扬声器外放，麦克风把扬声器的声音又收了进去。**

**解决办法只有一个**：戴耳机。

软件端的"回声消除"能缓解。

但它会明显损伤音质，还可能产生半双工效果：你一说话，队友就听不到游戏声。

**耳机是唯一干净的解法。**

# 六、推送说话（Push to Talk）

很多团队游戏默认用「按键说话」。

**如果你的按键设成了游戏里也用的键，就会出现"打架"。**

比如设成 Alt，你在游戏里按 Alt 看地图，队友就会听到你的键盘声。

**建议**：

- 设一个游戏里几乎不用的键（比如侧键）
- 或者改用「语音激活」，再配合噪声抑制

这两种都有代价，得试。

# 七、一个检查清单

按顺序走一遍：

- 系统输入音量到 100%
- 设备属性里看「麦克风加强」
- 开噪声抑制
- 戴耳机（解决回音）
- 检查「按键说话」的键有没有和游戏冲突
- 录一段自己的声音回放，实际听一遍

最后那条最有用，很多人从来没听过自己的麦是什么声。
