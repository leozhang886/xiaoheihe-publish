"打 FPS 第一件事，把鼠标加速关掉。"

这句话你肯定听过。它基本是对的，但**大部分人不知道自己关的是什么**，也不知道它管不管用。

结果是：关完发现手感没变化，然后怀疑是自己的问题。

# 先搞清楚你关的是哪个

绝大多数教程说的"关鼠标加速"，指的是 Windows 里的这一个：

**控制面板 → 鼠标 → 指针选项 → 取消勾选"提高指针精确度"**

这个选项的作用是：**你手移动得快，指针就走得比实际距离更远。**

比如你手腕甩一下移动了 5 厘米，慢慢移指针走 500 像素，快甩可能走 1500 像素。同样的手部动作，屏幕上的结果不一样。

**为什么 FPS 玩家要关它**：射击游戏靠的是肌肉记忆——"手腕转这个角度，准心从这儿到那儿"。如果同样的动作结果不固定，肌肉记忆就建立不起来。

这个逻辑没问题。但问题在下一步。

# 关键：它对很多游戏不生效

**现在主流 FPS 大多用 raw input（原始输入）。**

意思是：游戏不走 Windows 那套指针流程，而是**直接从鼠标读原始数据**。Windows 那个"提高指针精确度"是在指针流程里做手脚的，游戏绕过这条路，自然也就绕过了这个设置。

所以会出现这种情况：

**你关掉了"提高指针精确度"，进游戏一试，手感一模一样。因为游戏压根没理它。**

**那它到底影响什么？**

- 桌面上的光标移动（这个确实变了，而且是变好）
- 游戏里的菜单和界面
- **不用 raw input 的游戏**——一些 RTS、老游戏、或者把原始输入做成可选项的游戏

所以那个开关该关吗？**该关。** 但你要知道，你关它是为了让桌面和界面正常，不是为了让枪法变好。

# 想要真正可控的加速，得用别的工具

如果"加速"这件事本身不是原罪，那有没有办法用一条**自己能控制**的曲线？

有。这就是 [Raw Accel](https://github.com/RawAccelOfficial/rawaccel) 干的事。

**它的数据**：★2,556，MIT 协议，内核态驱动。

**它和 Windows 那个开关的区别在哪**：Raw Accel **直接改 raw input 流**。也就是说，那些绕过 Windows 指针流程的游戏，**它管得着**。

**反作弊方面它做了三件事**（这三点写在官方 README 里）：

1. 驱动**有签名**，运行在系统层
2. 只按**一组固定公式**修改输入，不做别的事
3. **改设置时会强制加一秒延迟**，防止被拿来做自动化

**还有一个必须说的安全提醒**：官方 README 明确写了，它和 `rawaccel.net`、`rawaccel.com` 这些网站**没有任何关系**。官方版本只在 GitHub 那个仓库里。你搜这个名字会搜出一堆长得像官网的站点，**别从那里下**。

顺便说，Raw Accel 的前身是 [InterAccel](https://github.com/KovaaK/InterAccel)（★338），作者是 KovaaK——就是那个做瞄准训练软件的人。

# 那为什么有人主动要加速

这就回到一个更根本的问题：**加速一定是坏事吗？**

不是。它是个取舍。

**不加加速**意味着：灵敏度固定。瞄准准，但转身慢——你鼠标垫就那么大，手划到头就转不了更多了。

**加加速**意味着：慢速移动时灵敏度和原来一样（瞄准精度不受影响），快速甩的时候能多转一些。代价是**快速甩的那一段靠肌肉记忆会难一点**。

Quake 圈的职业选手一直有人用加速，就是这么个道理。他们追求的是一块小鼠标垫上又能精确瞄准、又能 180 度转身。

**所以关键不是"加不加速"，是"这条曲线你能不能控制"。** Windows 那个开关是一条写死的曲线，你既不能调也不能关掉它的某一段。Raw Accel 给的是可调的。

# 那到底该怎么做

**打 FPS，先确认一件事**：你玩的游戏有没有用 raw input。

有些游戏在设置里直接给了"原始输入"或者"鼠标原始数据"的开关，看一眼就知道。大部分现代 FPS 是默认开的。

**然后分三种情况**：

**什么都不想折腾**——把"提高指针精确度"关掉。桌面舒服，游戏里有没有用随缘。

**想要加速，或者想自己调**——用 Raw Accel，从官方 GitHub 仓库下。

**不想要加速**——那你要确认的是**游戏里的**鼠标设置，不是 Windows 的。找游戏里的"鼠标平滑""加速"这类选项，那个才真正影响你。

# 最后

这篇想说的其实是一件事：

**"关掉鼠标加速"这条建议没错，但它被传成了万能药。** 你关的那个开关，可能只是让桌面光标正常了一点。

真正影响手感的，是游戏本身有没有绕开系统、以及你在游戏里选了什么。

你玩 FPS 会关加速吗？关完感觉有变化没？
