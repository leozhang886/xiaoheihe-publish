我见过最亏的一种情况：花大价钱买了台 144Hz 的显示器，插上就用，三年过去，一直跑在 60Hz。

他自己完全不知道。画面也能看，游戏也能玩，就是那多花的钱从来没生效过。

下面这四个地方，属于"默认值不等于最佳值"的那一类。买完显示器花几分钟查一遍，能少亏很多。

# 一、刷新率

这个是最要紧的，也是最容易漏的。

**它是什么**：屏幕每秒重画多少次。60Hz 就是每秒 60 次，144Hz 就是 144 次。你买高刷屏多花的钱，买的就是这个数字。

**为什么默认是 60**：Windows 装好之后，刷新率常常停在 60Hz，得手动改。它不是自动认的。

**怎么查**：在 Windows 搜索栏输入「查看高级显示信息」，打开，看「选择重新整理的频率」那一栏。

如果是 60Hz，而你的屏幕是 144Hz 或者更高，点开改成最高的那个。

**笔记本还要注意一点**：很多游戏本有"省电模式"或者"混合显卡模式"，切过去之后刷新率会被降回 60Hz。插电玩游戏的时候记得看一眼。

# 二、色深

这一条知道的人更少。

**它是什么**：每个颜色通道用几位数字表示。

- 8bit：每个通道 256 级，合起来约 1670 万色
- 10bit：每个通道 1024 级，合起来约 10.7 亿色

**为什么要在意**：8bit 不够用的时候会出现**色彩分层**——天空、烟雾、暗部渐变这些地方，本来该是平滑过渡，结果变成一条一条的色带。

**关键点是这个**：市面上很多 10bit 显示器，默认只输出 8bit。你不去改，它就一直按 8bit 跑。

**怎么改（N 卡）**：打开 NVIDIA 控制面板 → 左侧「更改分辨率」→ 右侧勾「使用 NVIDIA 颜色设置」→「输出颜色深度」选 10 bpc → 应用。屏幕会黑一下，那是正常的。

**有个前提**：线材得够。DP 建议 1.2 以上，HDMI 建议 1.4 以上。用老线的话，带宽不够，选项可能是灰的或者改不动。

改完回到「高级显示设置」看一眼，确认系统认到了 10bit。

# 三、可变刷新率（G-Sync / FreeSync）

**它是什么**：让屏幕的刷新跟着显卡的帧数走。

平时屏幕按固定频率刷新，显卡出帧的速度却是波动的。两边对不上，画面就会撕裂（上半张是旧帧、下半张是新帧）或者卡顿。

开着 V-Sync 能解决撕裂，但会引入延迟。可变刷新率是第三条路：屏幕等显卡，来一帧画一帧。

**N 卡叫 G-Sync，A 卡叫 FreeSync，技术上是同一件事。**

**它最容易漏在哪**：这个功能通常要在**三个地方**都打开才生效。

1. 显示器自己的菜单里（OSD）——很多显示器出厂是关的
2. 显卡驱动里——N 卡是「设置 G-SYNC」，A 卡是「FreeSync」
3. Windows 里——设置 → 系统 → 显示 → 图形 → 默认图形设置 → 「可变刷新率」

三个里漏一个，它就不工作。而最常漏的是第一个，因为没人会想到还要去按显示器上的实体按钮。

# 四、缩放模式

**它是什么**：游戏分辨率跟屏幕分辨率不一致的时候，怎么把它撑满屏幕。

**三种常见选项**：

- **全屏拉伸**：铺满整个屏幕，但画面会被拉变形
- **保持比例**：按原比例放大，周围留黑边，画面不变形
- **不缩放**：画面居中显示，四周全是黑边

**在哪改**：显卡控制面板里。N 卡是「调整桌面尺寸和位置」，A 卡在显示设置里。

**为什么值得看一眼**：如果你玩老游戏，或者显卡带不动原生分辨率要降一档，这个设置直接决定画面是变形还是留黑边。默认值不一定是你想要的那个。

# 一张自检清单

抄下来，对着查：

1. **刷新率**：搜索「查看高级显示信息」，确认不是 60Hz
2. **色深**：显卡控制面板里看「输出颜色深度」，能上 10bpc 就上
3. **可变刷新率**：显示器菜单 + 显卡驱动 + Windows，三处都开
4. **缩放**：显卡控制面板里选「保持比例」，除非你就是要拉伸

四项加起来花不了五分钟。

# 最后

这四个地方的共同点是：**厂商不会提醒你，系统也不会**。

它们不影响你能不能玩，只影响你玩得好不好。所以特别容易被放过——一直到一个懂行的朋友坐到你电脑前，随口问一句"你这屏多少赫兹啊"。

你查过自己的吗？是多少？
