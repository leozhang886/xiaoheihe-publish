![](assets/cover-score-vs-review.png)

媒体给 90 分，Steam 好评率 92%。

**买回来玩了四小时，放下了。**

**不是被骗，是这两种数字都不回答"适不适合我"。**

# 一、媒体评分测的是什么

测的是"工艺水平"。

画面、演出、系统完整度、有没有明显缺陷。

**它不测"你喜不喜欢这个类型"。**

**所以一个 90 分的赛车游戏，对不爱赛车的人毫无意义。**

# 二、好评率测的是什么

测的是"预期落差"。

好评 = 符合或超出预期，差评 = 低于预期。

**问题在于，预期是买之前就有的。**

**一款定位精准的小众游戏，好评率可能比 3A 还高。**

# 三、差评才是信息量最大的

**看好评只能知道"大家喜欢"，看差评才能知道"哪类人不喜欢"。**

**差评里反复出现的词，就是这游戏的雷点。**

比如：

- "太肝" → 时间投入大
- "剧情拖" → 节奏慢
- "优化差" → 配置要求高

**这些词对别人的意义，比总分大得多。**

# 四、一个具体的判断方法

**在差评里搜三个词：你受不了的东西。**

**比如你讨厌重复刷，就搜"重复""刷"。**

**如果差评里这类词出现频率很高，那这游戏不适合你。**

哪怕它总分很高。

# 五、还有一种数字最没用

"特别好评"这个标签。

它把 90% 和 95% 都归到一类。

**而实际体验里，这两者差很多。**

**看具体百分比，别看标签。**

# 六、奖项也一样

**奖项是行业视角的认可。**

**它证明作品完成度高，不证明它适合你。**

**这两件事经常被混在一起。**

# 七、我的建议

顺序反过来：

- 先看差评找雷点
- 再看好评确认优点
- 最后才看总分和奖项

**总分只用来筛掉有明显缺陷的，不用来做决定。**

你买过评分很高但玩不下去的游戏吗？
