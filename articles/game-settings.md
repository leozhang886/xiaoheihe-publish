大部人装了游戏就直接开玩，设置页从进到出不超过十秒。

可以理解。但有一类选项，默认全开，作用只是"让画面更像电影"，代价是你玩游戏时的清晰度。

下面这六个，值得花两分钟看一眼。

**先说清楚对比图是什么**：底图是一张真实的游戏截图（天国拯救2），效果是我按各个选项的光学原理模拟上去的。不是某个游戏的实拍对比——每家的实现都不一样，但方向是一致的，看图能明白开关的差别在哪。

# 一、动态模糊

**它做什么**：你转视角的时候，把画面糊掉。

**为什么默认开**：模仿电影的运镜。电影一帧曝光时间长，快速移动必然带拖影，游戏想还原这个感觉。

**关掉会怎样**：转视角时画面是清楚的。字面意义上看得更清。

**顺带一提**：很多人说的"晕 3D"，跟这个有关。转视角时画面糊成一片，眼睛收到的信息和身体感觉对不上，就容易难受。如果你有这个问题，先关它试试。

![](assets/settings/01-motion-blur.jpg)

# 二、胶片颗粒

**它做什么**：往画面上叠一层噪点，模拟胶片质感。

**为什么默认开**：让画面显得"有味道"，不那么干净得像塑料。

**关掉会怎样**：画面变干净。在高分辨率下差别尤其明显——颗粒会盖掉很多细节。

**这条我不劝**。有人就是喜欢那个味道。你自己看一眼，喜欢就留着。

![](assets/settings/02-film-grain.jpg)

# 三、色差

**它做什么**：画面边缘出现红蓝色边。

**为什么默认开**：模拟老镜头的色散。这是一种**故意还原的镜头缺陷**。

**关掉会怎样**：边缘干净了。开着头晕的人也不少。

![](assets/settings/03-chromatic.jpg)

# 四、暗角

**它做什么**：把画面四角压暗。

**为什么默认开**：把注意力往画面中心引，同时制造压迫感。

**关掉会怎样**：四角看得见了。在需要观察环境的游戏里（潜行、搜刮），这条挺影响体验。

![](assets/settings/04-vignette.jpg)

# 五、景深

**它做什么**：模仿相机对焦，焦点以外的部分虚化。

**为什么默认开**：让画面有层次，对话场景里常用。

**关掉会怎样**：整幅画面都在焦点上。找东西的时候，能少瞪一会儿。

![](assets/settings/05-dof.jpg)

# 六、镜头抖动

**它做什么**：爆炸、受击、跑步的时候晃屏。

**为什么默认开**：增加冲击力，让打击感更实。

**关掉会怎样**：画面稳了。跟动态模糊一样，这也是晕 3D 的常见来源。

**这条我没做对比图。** 它是动态的——屏幕一直在晃，静态截图表现不出来。你自己进游戏打着试试，感觉晃就关。

# 另外单独说一个：视野（FOV）

这个不属于上面那类，但值得看。

主机游戏的默认视野通常偏窄，因为玩家坐在沙发上、离电视远。这套默认值搬到 PC 上，就变成了"贴脸视角"——画面挤，人也容易晕。

**PC 玩家如果觉得画面太挤，先去调 FOV。** 大多数游戏都有这个选项，有些藏在"高级"或者"无障碍"分类里。

![](assets/settings/06-fov.jpg)

# 最后

这些话的前提是：**上面六条都是审美选择，不是错误。**

厂商加它们，是为了让你看到他们想要的画面。你要的可能是另一种。两种都没问题，区别只在于——**你得知道有得选。**

而且改起来不要钱，也不用重启。不满意随时改回去。

你进游戏会先翻设置吗？有没有哪一条是你必关的？
