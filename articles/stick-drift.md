手柄用久了，角色自己往前走，视角自己转。

这叫摇杆漂移。

**多数人的第一反应是换手柄，其实有几步可以先试。**

# 一、漂移到底是怎么来的

**摇杆下面是两个电位器，靠电阻变化判断位置。**

磨损之后，静止时的电阻值会偏移。

**手柄就以为你推了一点，其实你没动。**

**所以漂移通常是硬件老化，不是软件问题。**

# 二、先排除软件

三件事，五分钟：

- 换一根线或者重新配对
- 在系统里看摇杆原始输入
- 换一个游戏试

**如果原始输入就是偏的，那基本确定是硬件。**

**如果只有某个游戏漂，那是死区设置的问题。**

# 三、死区能救一部分

**很多游戏有「摇杆死区」设置。**

**调大死区，漂移就感知不到了。**

代价是轻微操作会变迟钝。

这是缓解，不是修复。

# 四、校准

部分手柄支持软件校准。

**按厂商的工具走一遍，有时能让偏移回到中心。**

**校准解决不了磨损，但能修正"中心点记错"的情况。**

**成功率不高，但成本为零。**

# 五、清洁

**摇杆缝隙里的灰尘会影响电位器。**

**压缩空气吹一下，或者拆开用无水酒精擦触点。**

**这条对"突然开始漂"的情况有效。**

对长期磨损效果有限。

# 六、换摇杆模块

**有些手柄的摇杆模块是独立可换的。**

**成本比换整只手柄低很多。**

**需要注意的是焊接和校准——不会焊的话找店。**

# 七、什么时候该换

三条红线：

- 死区调到很大还是漂
- 校准后手感明显不对
- 换模块的成本接近新手柄的一半

**到这三条，换新的更划算。**
