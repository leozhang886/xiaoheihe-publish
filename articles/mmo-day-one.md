新 MMO 开服，很多人第一件事是冲等级、刷装备。

顺序错了。

**开服那几天的效率差距，会滚一个月。**

# 一、先跑主线

主线解锁功能。

地图、副本、日常、坐骑、公会，**这些通常都是主线开的。**

**不跑主线，后面很多事做不了。**

**所以第一优先级永远是主线，不是刷怪。**

# 二、把背包和仓库开满

**这是最容易被忽略的一条。**

开服阶段背包永远不够用，每次满包都要回去清。

**前期花点钱把格子开满，省下的时间远超那点金币。**

仓库同理。

# 三、加个公会

**开服当天公会最好进。**

过几天位置就满了，进门槛也高了。

**而且早期的公会成员，后期往往是固定队。**

**这一条的价值在长期。**

# 四、别急着刷装备

**开服阶段的装备很快会被淘汰。**

你花十小时刷的那套，可能一周后主线就送你更好的。

**早期该做的是把等级推上去，把功能解锁完。**

装备等满级再说。

# 五、注意服务器的"第一波活动"

**开服活动通常有时限。**

而且要抢的东西（首杀、竞速、限时掉落）过了就没了。

**这个优先级可以往前放。**

# 六、一个反例

**很多人开服前两天肝到顶，然后没内容了。**

因为游戏设计是按照"普通节奏"设计的，**你跑太快，后面就是等更新。**

所以也别拼命冲。

# 七、我的建议

**顺序：主线 → 开格子 → 加公会 → 抢限时活动 → 满级后再搞装备。**

**这套顺序适用大部分 MMO。**

**唯一例外是你有固定队要抢首杀，那另说。**

你玩新 MMO 会先干什么？
