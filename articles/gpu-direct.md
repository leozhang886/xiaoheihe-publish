游戏本有个开关，很多人从来没动过。

**它能让帧数白涨一截，而且不花钱。**

叫「独显直连」，或者「GPU 直连」「MUX Switch」。

# 一、为什么会有这个开关

笔记本为了省电，默认走的是混合模式。

**画面由独立显卡渲染，但要经过核显输出到屏幕。**

**多绕一道，就有损耗。**

**独显直连的意思是：让独立显卡直接输出，绕过核显。**

# 二、代价是什么

开直连会更费电。

核显被跳过，就没法帮独显省电了。

**所以厂商默认不开。**

**代价是性能，收益是续航。**

# 三、能涨多少

普遍的说法是 5% 到 15%。

**竞技类游戏提升更明显**，因为对延迟敏感。

**单机大作往往涨得少**，因为瓶颈常在显卡本身。

**具体多少取决于机型和游戏，没法给统一数字。**

# 四、怎么判断自己有没有

三个地方找：

- **厂商自带的控制中心**（华硕、联想、惠普都有自己的软件）
- BIOS 里
- **有些机器要重启才生效**

**名字可能叫：独显直连、GPU 直连、MUX、dGPU Mode。**

找不到就是没有。 老机型或者轻薄本经常没有这个功能。

# 五、什么情况别开

**这几种建议保持混合模式：**

- 经常拔电用
- 主要在外办公
- 玩的是轻度游戏

这几种建议开：

- 一直插电用
- 打竞技游戏
- 外接显示器（外接本身通常就是直连）

# 六、一个容易忽略的点

**外接显示器一般是直接连独显的。**

所以你已经外接了一块屏，**主屏的直连开关影响就小了**。

**这一点很少有人讲清楚。**

# 七、我的建议

**先查有没有这个功能。**

有的话，插电打游戏时开着，拔电时关掉。

**这是零成本的性能提升，值得花五分钟找一下。**

你的游戏本有这个开关吗？
