![](assets/cover-drift.png)

摇杆松手了，人物还在慢慢走。

这就是漂移。用久了的手柄几乎都会碰到。

结论先给：轻度清洁能救，中度换模块，重度换手柄。

判断走哪条路，看两件事——漂移有多严重，手柄还值不值修。

# 一、漂移是怎么来的

摇杆底下有个元件在测你推了多少、推到哪个方向。

主流方案是碳膜电位器。

它靠一片金属刷子在碳膜上滑动来改变电阻。

刷子在膜上摩擦，膜会磨薄，磨下来的碎屑还会积在里面。

磨到一定程度，静止时它输出的就不是零了。

手柄以为你在推，于是人物自己走。

这就是漂移。**它是物理磨损，不是软件问题。**

所以重启手柄、重装驱动都没用。

# 二、霍尔摇杆为什么被吹

霍尔摇杆用磁场感应，没有物理接触。

没有摩擦，就没有磨损。

这就是为什么现在中高端手柄都在宣传霍尔。

但别以为它是万能药。

霍尔躲的是"刷子磨损"，躲不掉这些：

- 磁铁位置松动导致偏移
- 长期使用后的零点漂移
- 出厂校准不准

也就是说，霍尔不会像碳膜那样磨坏，但依然可能需要重新校准。

它的优势是寿命长得多，不是永不漂移。

# 三、先确认是不是真漂移

别凭感觉。去测一下。

[gamepad.js](https://github.com/bwiklund/gamepad.js)（★561）

网页版的 Gamepad API 测试器。打开浏览器连上手柄就能用，不用装任何东西。

看那个轴的数值。

手完全松开的时候，两个轴的读数应该都在 0 附近。

![](assets/drift-diagnosis.jpg)

**静止时稳定偏在某个非零值上，那就是漂移。**

如果只是轻微跳动（比如 ±0.02），那可能是死区设置的问题，不是硬件坏了。

**这一步很重要。** 很多人以为自己漂移了，其实只是死区太小。

另外两个可以试的：

- [Polling](https://github.com/cakama3a/Polling)（★255）——测延迟和回报率
- [MultiPadTester](https://github.com/nefarius/MultiPadTester)（★28）——Windows 手柄测试器，能对比不同后端

# 四、轻度漂移，先清洁

偏移量不大的话，值得先试清洁。

需要的：高浓度异丙醇（90% 以上）、棉签。

做法：拆开手柄，找到摇杆模块，用棉签蘸异丙醇清理电位器周围。

原理是把磨下来的碎屑和积灰清掉，让刷子重新接触干净的地方。

**但风险要说清楚：**

- 拆机基本等于放弃保修
- 异丙醇不能大量灌进去，会损坏其他元件
- 装回去时排线容易压坏

清洁的成功率不高，属于"值得一试"而不是"包治"。

清完没好转就得往下一步走。

# 五、换模块值不值

**看手柄价格。**

现在很多手柄的摇杆是独立模块件，网上能买到。

但换模块的账要这么算：零件钱加上你的手工时间。

如果手柄本身三百块以内，换模块要花一百多再加上拆机风险，不如直接换新。

如果是七八百的旗舰手柄，换模块就明显划算。

# 六、什么时候直接换

这几条中一条，就别修了：

- 除了漂移还有别的毛病（按键失灵、震动坏了）
- 已经拆过、清洁过，还是漂
- 手柄不贵，修的钱接近买新的
- 你不想折腾

换新的时候有个建议：优先看霍尔摇杆的型号。

不是因为它永不漂移，是因为它的磨损方式比碳膜慢得多。

# 七、怎么让手柄活得久

- **别在摇杆上用力。** 玩格斗或者赛车习惯性推到底还继续压，那是在加速磨损
- **别摔、别放灰大的地方。** 灰尘进到电位器里是最快的杀手
- **不用的时候收进盒子。** 尤其是吃灰的书架，那是漂移的温床
- **两个月测一次零点。** 用上面那个网页工具，早点发现早处理

# 八、别为修一个便宜手柄花它一半价钱

漂移的本质是：摇杆是个机械件，机械件一定会磨损。

所有"彻底解决"的说法都要打折看。

碳膜是磨坏，霍尔是老化。前者更快，后者更慢，但都不是永久。

所以我的建议是：测一下确认，轻度先清洁，重度算成本。

别为了修一个便宜手柄，花掉它一半的价钱。

你手柄漂过吗？最后是修了还是换了？
