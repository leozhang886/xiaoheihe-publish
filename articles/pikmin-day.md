任天堂正式把 **11 月 1 日**定为「皮克敏日」。

还开了一场皮克敏为主题的直面会。

**给一个非主力 IP 设年度节点，这在任天堂身上不常见。**

# 一、皮克敏是个什么体量

说实话，它从来不是任天堂的门面。

销量比不上马里奥、塞尔达、宝可梦，**连动森都比它高一个量级。**

但它的口碑一直很稳。

**评价高、销量平**，这是皮克敏长期的状态。

# 二、为什么还要给它设节日

我觉得有两个原因。

**第一，它需要被记住。**

不设节点，这个 IP 就慢慢沉下去了。

**第二，它的形态适合做节日。**

皮克敏的核心玩法是种植物、带小生物——**天然的“季节感”和“养成感”**。

比起给射击游戏设节日，给皮克敏设更自然。

# 三、任天堂的一贯做法

它很少放弃 IP。

**马里奥、塞尔达、火狐、银河战士，都被雪藏过，又都被捞回来过。**

任天堂的逻辑不是“卖不爆就砍”，而是**“留着，等一个合适的机会”**。

**皮克敏日就是这种思路的产物。**

# 四、这次的直面会说了什么

重点是新作和系列回顾。

**但对国内玩家来说，实际影响有限**——皮克敏没有国行，也没上 PC。

**这是一个典型的“看着热闹、玩不到”的新闻。**

# 五、说点不好听的

**这个节日的商业价值，可能比情怀价值小。**

皮克敏的受众太窄，设个日子也很难拉新。

真要拉新，不如降个价，或者出个合集。

**但任天堂显然更愿意做“长期品牌”，而不是短期促销。**

# 六、我的判断

这件事对 PC 玩家的实际意义不大。

**但它是观察任天堂的一个窗口：**

这家公司愿意花几十年养一个不赚钱的 IP。

**短期看是浪费，长期看是护城河。**

你觉得任天堂该不该继续养皮克敏？
