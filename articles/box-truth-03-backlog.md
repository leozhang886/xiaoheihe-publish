打折那天你买了六个游戏。第二天打开库，划了两下，关掉了。然后又点开了那个玩了八百小时的老游戏。

这事我熟。

但我想说的不是"要自律"。**这不是意志力问题，是设计问题。**

# 先说个可能不好听的

买游戏那一刻的爽，跟玩游戏那一刻的爽，**不是同一种爽**。

玩游戏要付出：要学系统、要过教程、要接受前两小时的笨拙。买游戏不用，点一下，付款，结束。多巴胺来得又快又便宜。

所以你不是"买了不玩"，你是**在买"我以后会玩"这个念头**。

这个念头本身是有价值的——它让你感觉自己的生活里还有位置放这些东西。但它是念头，不是游戏。

![](assets/box-truth-03-backlog.png)

# 为什么打折特别容易让人失手

因为打折制造的是**稀缺感**，不是需求。

一款你原价时看都没看的游戏，打到两折，突然就"值得拥有"了。它没变，变的是"错过就亏"这个感觉。

更麻烦的是，打折是**成批来的**。特卖页面一屏十几个折扣标签，你的判断力在第三个的时候就没了。

# 有个工具专门治这个

我搜了一圈，发现 GitHub 上有个项目叫 [Depressurizer](https://github.com/Depressurizer/Depressurizer)（★1,527），干的就是这件事：**给你的 Steam 库分类**。

它能把库按标签、时长、评分自动分组，你一眼就能看出来自己堆了多少没碰过的。

**为什么这个有用**：吃灰的本质是"看不见"。库里的游戏混成一团，每次打开都是一次选择困难，选择困难的结果就是去点那个熟悉的老游戏。

分类不解决"你想不想玩"，但解决"你根本不知道自己有什么"。

# 还有一个坑：你不知道这游戏有多长

"五十小时内容"是宣传语，不是承诺。

有的游戏五十小时里有三十小时是采集和跑腿；有的游戏标二十小时，但节奏紧到你一口气通关。

**买之前查真实时长**这件事，也有人做了工具：[HowLongToBeat 的 API](https://github.com/ckatzorke/howlongtobeat)（★420），还有把它接进库管理软件的[插件](https://github.com/Lacro59/playnite-howlongtobeat-plugin)（★181），能在你翻库的时候直接显示主线多久、全收集多久。

**为什么这条重要**：你说"以后会玩"，其实是在赌"以后我有五十小时"。先看看这个数字，赌注会清楚很多。

# 我自己的三条规矩

**一、打折期间不买"以后可能会玩"的。**

只买"这周就想开"的。想开就是现在，不是以后。这条砍掉了我八成的冲动购买。

**二、一次只玩一个。**

听着像小学生守则，但它是真的有用。库里同时挂着五个"在玩"，等于一个都没在玩。

**三、允许自己放弃。**

玩了两小时发现不对胃口，就删掉。留在库里当"待办"，只会让你每次打开库都多一分愧疚。**游戏是消遣，不该变成任务清单。**

# 最后

我不觉得买多了是道德问题，也不觉得该为此自责。

只是有件事值得想清楚：**你花钱买的是游戏，还是"以后的我"？**

前者你随时能玩。后者永远在以后。

你库里有多少是买完没碰过的？评论区说说，我猜不比我的少。
