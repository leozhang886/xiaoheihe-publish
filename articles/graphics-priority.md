帧数不够，第一反应是把画质从“高”调到“中”。

**这是最亏的做法。**

画质选项里，**不同项的性价比差几十倍**。

# 一、最吃性能的三样

按普遍情况排序：

- 阴影质量
- **体积云 / 体积雾**
- **屏幕空间反射**

**这三样加起来，经常能吃掉 20% 以上的性能。**

而且它们的视觉效果，**在快速移动时你根本注意不到**。

# 二、为什么阴影最贵

阴影要重新渲染一遍场景。

**分辨率越高，这一遍的代价越大。**

阴影质量从“高”降到“中”，通常是把阴影贴图分辨率减半。

**视觉差异在静态截图里很明显，玩起来基本看不出。**

# 三、体积云为什么贵

它需要大量的采样计算。

**云层越细腻，每帧要算的采样次数越多。**

从“高”降到“中”，云会变平一点，**但天还是那片天**。

# 四、几乎免费的项

这几样可以放心拉满：

- 纹理质量（只要显存够）
- **各向异性过滤**
- 锐化

**纹理几乎不吃算力，只吃显存。**

你的显卡显存够（8G 以上基本够），纹理开最高也没关系。

# 五、贵但值得的项

- 抗锯齿
- 分辨率

**这两样直接影响“清不清晰”**，比阴影重要得多。

**宁可关阴影，别降分辨率。**

# 六、一张优先级表

**先关（性价比最高）：**

- 阴影质量
- 体积云 / 体积雾
- 屏幕空间反射

后关：

- 抗锯齿
- 纹理
- 各向异性过滤

**尽量别关：**

- 分辨率
- 帧生成（如果你帧数够）

# 七、一个提醒

**不同游戏的权重不一样。**

有些游戏阴影几乎不耗性能，有些游戏云层是大头。

**但“阴影和体积效果最贵、纹理最便宜”这个规律，在绝大多数游戏里成立。**

下次调画质，从阴影开始关。
