鼠标回报率从 1000Hz 拉到 8000Hz。

**纸面上，延迟降低 8 倍。**

**实际上，多数人感受不到，有些配置还会更卡。**

# 一、回报率是什么

鼠标每秒向电脑报告位置的次数。

- 1000Hz → 每秒 1000 次，间隔 1 毫秒
- 8000Hz → 每秒 8000 次，间隔 0.125 毫秒

**理论上，报告越频繁，操作越跟手。**

# 二、为什么实际感受不到

因为瓶颈不在鼠标。

- 显示器 144Hz，一帧 6.9 毫秒
- 1000Hz 鼠标，1 毫秒报一次

**鼠标早就在这个速度之上，再快也超不出屏幕刷新。**

**除非你是职业选手，用超高刷屏，否则收益接近零。**

# 三、代价是什么

**第一，吃 CPU。**

每秒处理 8000 次输入事件，是真实开销。

**弱一点的 CPU 上，这个开销会变成掉帧。**

**第二，无线鼠标的续航。**

高回报率耗电明显增加。

**第三，部分游戏不支持。**

超出引擎处理能力的输入会被丢弃或造成抖动。

# 四、什么时候值得开

- **有 360Hz 以上的屏**
- CPU 有余量
- **有线鼠标，或者能接受续航变短**
- 你是真的在打竞技

**四条都满足，再考虑。** 否则 1000Hz 是最稳的选择。

# 五、一个更重要的参数

**DPI 和游戏内灵敏度的配合，比回报率重要得多。**

**回报率是"报得多快"，灵敏度是"动多少"。**

**后者才真正决定手感。**

# 六、我的建议

**保持 1000Hz。**

**把时间花在调 DPI 和灵敏度上，收益大得多。**

**如果你的鼠标驱动默认开了 4000Hz，可以试着降回 1000**——说不定卡顿会好。
