电源是整机里最不该省的东西。

**但它是唯一一个坏了能带走全套配件的部件。**

# 一、80Plus 认证到底是什么

它测的是**转换效率**，不是质量。

- 白牌 80%
- 铜牌 85%
- 金牌 90%
- 白金 92%

**意思是一半的电变成了热。**

**注意：这个认证不保证用料、不保证寿命、不保证保护电路。**

所以“金牌”不等于“好电源”。

# 二、额定瓦数不等于能带

标称 650W，说的是总输出，不是每一路都能给满。

**关键看 12V 这一路。**

现在的显卡和 CPU 基本都吃 12V，**12V 输出能力才是实际能力。**

看参数时找“12V 输出 xx A”，乘 12 就是这一路的瓦数。

**有虚标的电源，12V 加起来远低于总额定值。**

# 三、单路和双路 12V

单路：所有 12V 输出合成一路，随便你分配。

双路：分成两路，各自有限制。

**现在主流是单路**，对高功耗显卡更友好。

双路如果某一路不够，可能出现“总功率够但带不动”的情况。

# 四、瓦数怎么估

粗略算法：

**显卡功耗 + CPU 功耗 + 100W 余量。**

比如显卡 250W、CPU 125W，那就是 475W，选 550-650W 比较稳。

**别正好卡在边缘。**

电源长期满载运行，寿命和稳定性都会打折。

# 五、比瓦数更该看的

- **电容**（日系普遍更耐用）
- **保护电路**（过压、过流、短路、过温）
- **保修年限**（敢给十年的一般不会太差）
- **风扇策略**（低负载停转，安静）

**这几样比“金牌”有意义得多。**

# 六、一句实话

**电源没法靠参数完全判断。**

它不像显卡有帧数、CPU 有跑分，**电源做得好不好，平时看不出来，坏的时候才知道。**

所以这一块，看口碑和保修比看参数可靠。

**这条也涉及用电安全，我的建议是别买来路不明的货。**
