写在前面：**这篇有 AI 辅助，先道个歉。** 数据我逐条核过，但句子不全是人手写的，读着有机器味的话是我的问题。

先给你看一个真实的数据。

荒野大镖客2 的终极版，原价 468，现在打 2 折，实付 93 块 6。

标准版，原价 279，打 2.5 折，实付 69 块 7 毛 5。

**折扣更狠的那个，反而贵了 24 块。**

这不是个例。折扣百分比这个东西，本来就很容易骗人。

# 为什么会被骗

因为折扣算的是"相对原价"，而每个版本的原价不一样。

终极版原价 468，砍掉 80% 还剩 93 块 6；标准版原价 279，砍掉 75% 也才 69 块 7 毛 5。你盯着"80% off"看，很容易觉得捡了大便宜，实际上你花出去的钱更多。

买游戏花的是**实付金额**，不是折扣数字。这句话听着像废话，但真到页面上，人是会被那个大红折扣标签带走的。

# 还有第二种坑：捆绑包

赛博朋克 2077 更绕一点。

本体原价 298，打 3 折，89 块 4。

终极版原价 411 块 24，只打 4 折，164 块 5。

单看折扣，本体更划算。但如果你想全都要，本体加 DLC 分开买是 89.4 + 89.4 = **178 块 8**，而终极版只要 164 块 5。

**终极版便宜了 14 块 3。**

原因是捆绑包在单品折扣之上又叠了一层。所以"折扣更小"的那个，在你买全套的时候反而是最优解。

# 那怎么查历史低价

这块我实测了一圈，结论可能有点扫兴：**没有免费的全自动方案。**

先说官方的。Steam 自己的价格接口只给你当前折扣，字段就是原价、现价、折扣百分比三个，**没有历史价**。这是我自己调接口确认的。

再说第三方的：

| 站点 | 结果 |
|---|---|
| SteamDB | **脚本抓不到，403**，有 Cloudflare |
| GG.deals | **同样 403** |
| IsThereAnyDeal | 页面能打开，但价格是 JS 动态渲染的，抓下来是空壳 |
| 其乐 | 能打开，但它是论坛，不是比价库 |

我也去 GitHub 搜了一圈，想找个现成的比价脚本。搜出来的要么是 CS2 饰品市场那类（跟买游戏没关系），要么是几个 star 的玩具项目，没有能直接用的。

**所以查史低这件事，目前只能在浏览器里手动看。** SteamDB 那个价格曲线图依然是最准的，只是它防爬，脚本别想碰。

# 几条实用的

**只认实付价格。** 看到折扣标签先别激动，往右看一眼真实金额。

**买全套之前，算一下总价。** 本体 + DLC 分开买，和直接买终极版，经常差出十几二十块。差在哪边不一定，得算。

**注意"原价"本身。** 有些游戏会永久降价，降完之后再打折，折扣数字会变好看，但实付不一定比当年便宜。

**加愿望单。** Steam 会在愿望单游戏打折时通知你，这是最省事的办法，不用天天自己蹲。

# 最后

两个例子摆在一起看，规律其实很简单：**折扣是商家想让你看的东西，实付是你要掏的东西。**

按实付做决定，就不会错。
