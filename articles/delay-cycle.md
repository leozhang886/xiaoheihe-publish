每次游戏跳票，公告里的新日期几乎都是「六个月后」。

为什么总是半年？

# 一、压盘和认证是硬周期

**实体版要提前几个月生产。**

压盘、包装、物流、铺货到各地零售，这一套走完至少两三个月。

**主机平台还有认证环节。**

索尼、微软、任天堂都要审核，一次没过就得改完重提。

**所以厂商不敢报太近的日期。**

# 二、避让竞品也是原因

**年底和春季是发售高峰。**

同一周撞上两个大作，谁都卖不好。

**跳票有一部分是商业判断，不是开发问题。**

# 三、但最真实的原因通常是没做完

**上面那些是加分项，不是主因。**

大多数跳票，本质就是没做完。

而且这个"没做完"往往不是差一点，是差了关键的一块。

**六个月这个数字，大概等于"重做一轮主要系统"的时间。**

# 四、为什么不报三个月

**报得近，压力大。**

三个月后再跳一次，舆论会更难看。

**报远一点，有缓冲，也留了提前发售的余地。**

**所以"六个月"其实是个保守估计，不是精确工期。**

# 五、什么情况下该担心

**一次跳票：正常。**

**连续两次跳票：要留意。**

**跳票之后没有任何实机演示：最该担心。**

**反过来，如果跳票同时放出了大量实机，那大概率是真的在做收尾。**

# 六、一个反面的例子

**有些游戏跳票之后反而变差了。**

因为时间被拿去加内容、改方向，越改越散。

**延期不等于变好，这一点得说清。**

# 七、我的建议

**看到跳票，先看它给了什么。**

给了新实机、给了具体功能说明，那可以等。

**只发了一封道歉信，那就要做好再跳一次的准备。**

你能接受跳票几次？
