我打算每周扒一遍 GitHub 榜单，挑 5 个跟游戏沾边、玩家真能用上的项目。这是第一期。

**先说本周的一个现象**：游戏机相关的项目在扎堆。PS5 移植工具、PS4 模拟器、PS Vita 模拟器、Xbox 360 重编译，全挤在周榜上。背后大概是同一件事——老平台的游戏越来越难玩到，社区在往回捞。

![](assets/gh-weekly/weekly-board.jpg)

下面这 5 个是我从里面挑的，标准是：**合法、活跃、玩家能直接用上**。

# 一、Moonlight：把 PC 游戏串到别的设备

★19,054 · 本周 +173 · 4 天前还在提交 · GPL-3.0

**它是什么**：串流客户端。装在你想"看画面"的那台设备上——手机、平板、电视盒子、或者另一台电脑——然后把主力 PC 上的游戏串过去玩。

**有个坑得先说明白**：Moonlight 只是客户端，它需要一个服务端。以前用 NVIDIA 的 GameStream，但**GameStream 在 2023 年就被 NVIDIA 砍掉了**。现在的事实标准是开源的 **Sunshine**，两个配合才是完整方案。

**能力**：H.264 / HEVC / AV1 编码，HDR 串流，7.1 声道，最多支持 16 个手柄，键鼠也能直通。Windows / Mac / Linux / Steam Link 都有，手机端有 Android 和 iOS。

**为什么值得看**：跟 Steam Link 比，它更开放——不限于 Steam 游戏，手柄兼容也更宽。如果你家里有一台吃灰的电视盒子或者旧手机，配上就能当串流终端用。

# 二、shadPS4：PS4 模拟器

★33,430 · 本周 +370 · 今天还在提交 · GPL-2.0

**它是什么**：PS4 模拟器，支持 Windows / Linux / macOS / FreeBSD。官网是 shadps4.net。

**怎么判断能不能玩**：README 里放的展示图是《血源诅咒》《初音未来 Project DIVA》《如龙 0》《驾驶俱乐部》。但这只代表"能跑起来"，**不代表能玩通**。

**这是模拟器类项目的通用规矩**：一定要先看官网的兼容性列表，别只看宣传图。同一个模拟器，A 游戏满帧、B 游戏闪退，太正常了。

**为什么值得看**：PS4 模拟这两年是进展最快的一档。血源诅咒一直没上 PC，这是很多人关注它的原因。

# 三、Vita3K：PS Vita 模拟器

★5,817 · 本周 +44 · 1 天前还在提交 · GPL-2.0

**它是什么**：PS Vita 模拟器，支持 Windows / Linux / macOS / **Android**。

**官方原话是"实验性"**，这个定位自己得认。它说能跑"大部分自制程序和商业游戏"，而且兼容性页面分了两份——自制游戏和商业游戏分开列，这个做法挺诚实。

**展示的游戏**：《女神异闻录 4 黄金版》《VA-11 HALL-A》《水果忍者》。

**为什么值得看**：PS Vita 是台被索尼放弃的掌机，很多独占游戏再也没移植过。**它支持 Android**——在手机上跑掌机游戏，这个对没有 Vita 的人意义更大。

# 四、Pumpkin：用 Rust 重写的 Minecraft 服务端

★12,320 · 本周 +407 · 今天还在提交 · GPL-3.0

**它是什么**：完全用 Rust 写的 Minecraft 服务端。目标三个词：快、省资源、可定制。

**技术上做的事**：靠多线程压性能，同时兼容 Java 版和基岩版（基岩版还在开发中），做了区块加载/保存的多种策略。

**这里必须给个警告**：项目自己在 README 里标了 **"正在重度开发中"**，1.0 还没到，并且挂着一份公开的待办清单。**现在别拿它去开服**——红石、区块生成这些核心功能还没齐。

**为什么值得看**：跑 Minecraft 服务端吃内存是老毛病，用 Rust 重写是个认真的方向。**收藏观望可以，现在上生产不行。**

# 五、Steamodded：小丑牌的 mod 框架

★985 · 本周 +4 · 2 天前还在提交 · GPL-3.0

**它是什么**：《小丑牌》（Balatro）的 mod 加载器和注入器，用 Lua 写的。

**背景**：《小丑牌》本身没有官方 mod 支持，这是社区自己做的框架。它提供了一套 API 让别人写 mod。

**用起来简单**：装好框架之后，把 mod 文件丢进 Mods 目录就能用。文档在 docs.smods.dev。

**为什么值得看**：小丑牌是那种"一把接一把停不下来、但几百小时后会腻"的游戏，mod 是续命的主要手段。这个框架是目前社区里最主流的一个。

# 几句说明

**一、这些数据是我从 GitHub 榜单和接口上现扒的**，star 数、本周新增、最后提交时间都是抓取当天的真实数字。

**二、我故意没选两类项目。** 一类是"把主机程序移植到 PC"的工具——性质上和模拟器不一样，更容易惹麻烦；另一类是单机游戏修改器。这两类传播起来都有风险，我不想在一个公开社区里推荐。
