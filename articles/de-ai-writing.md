写在前面：**这篇有 AI 辅助，先道个歉。** 数据我逐条核过，但句子不全是人手写的，读着有机器味的话是我的问题。

你肯定见过这种文字。每个字都对，语法也没毛病，但读两行就知道是 AI 写的。

我自己用 AI 写了一段时间帖子，也被这个问题卡过。后来干脆去 GitHub 把专门做这件事的项目扒了一遍，一共 6 个，把它们的规则对照着看。

下面这 12 条是被反复提到的。你可以直接拿去对着自己的稿子改。

# 一、解说导引句

先说"我要说什么"，再说内容。把读者当傻子。

差：先说重点，本体 89 块
好：本体 89 块

这类词还有：值得注意的是、需要指出的是、这是关键、说白了、本质上、总的来说。

# 二、价值上升词

空洞地拔高，但不提供任何信息。

差：这个决定标志着我们对读者行为的重新思考
好：我们改了发送时间

意义深远、深刻地印证、完美融合、极大地、具有里程碑意义，都是这一类。

# 三、"不是……而是……"

差：真正的成长不是盲目尝试，而是持续学习
好：试错没用，得复盘

这个句式 AI 特别爱用，而且一用就显得端着。

# 四、排比和对仗

差：这不仅仅是一堂课，更是一场思维的革命

人聊天不会这么说话。看到"不仅仅……更是……"就该警觉。

# 五、破折号当拐杖

一句话说不完，就甩个破折号接着写。

中文里破折号本来就少用。一段里出现两次以上，基本可以确定有问题。

# 六、反问收尾

差：机会永远留给准备好的人，不是吗？

# 七、加粗淹没重点

一段一个加粗还行。每段都加粗，等于没加粗。

# 八、段落长度均匀

真人写东西，有的段落三行，有的就一句话。工整得像排版软件输出的，就是 AI。

# 九、通篇没有"我"

这条我觉得是最根本的。

AI 写的东西通常全是客观陈述，没有作者的位置。你得往里放自己的判断、自己的反应，哪怕是"我看到这个数字愣了一下"。

# 十、结尾客套

差：希望这篇文章对你有帮助。

# 十一、机械结构

"首先……其次……最后"、"第一……第二……第三……"。人写东西不会把话切得这么整齐。

# 十二、书面语和名词化

差：我们进行了一次实验
好：我们做了个实验

差：对系统进行了优化
好：把系统优化了

# 现成的工具，我列一下

GitHub 上做这件事的项目不少，但**活跃度差别很大**，别随便挑一个就用。

- **lieflat-less-ai-tone**（2275 星，41 天前更新）：基于 283 万字语料统计出来的规则，是目前星最多的
- **shuorenhua 说人话**（1974 星，1 天前更新）：中文优先，分场景处理，最近还在改
- **speak-human-tw**（1022 星，1 天前更新）：抓 38 种痕迹，但它是繁體中文向的
- **renwei-writing**（1086 星，113 天前）：偏"保留原作者语气"
- **De-AI-Prompt-Enhancer**（846 星，17 天前）：给作家用的提示词增强

**有个坑我得说。**

有个叫 `ai-flavor-remover` 的项目，1175 星，看着很靠谱。但它**最后一次提交在 550 天前**，整个仓库只有 12KB，连开源许可证都没写。

用它之前先看一眼更新日期。星高的不一定还能用。

# 怎么让它每次都生效

这是我这轮折腾下来觉得最有用的一点。

上面那些规则，你要是每次写东西都重新交代一遍 AI，累死。**写成一个固定的规则文件，让它自动加载**，就一劳永逸了。

Claude Code、Codex、Cursor 这类工具都有这个机制，通常放在项目根目录，叫 `AGENTS.md` 或 `CLAUDE.md`。DSH 支持全局，放在 `~/.dsh/AGENTS.md`，**所有对话都会读**。

把特征清单扔进去，之后每次生成都自动遵守。

# 我自己试的结果

我拿一篇已经写好的稿子对了一遍。改完的数字：

- 破折号：8 处 → **0**
- 加粗：约 15 处 → **1**

具体改了什么，举两个例子。

原文：因为终极版在单品折扣之上又叠了一层捆绑折扣——单看本体是打 3 折，但终极版是打 4 折，捆绑再减。

改成：终极版其实是折上折。本体单看是打 3 折，但进捆绑包按 4 折算，再叠一层。

原开头：先说重点：本体现在 89 块 4。

改成：本体 89 块 4。

说白了就两件事：**把拐杖拿掉，把话说短。**

# 最后

这套规则我用下来，它不是万能的。有些句子清完还是别扭，因为信息本身就绕。

但有一样是确定的：**清单可以照，但不能照单抓药**。把"值得注意的是"全删掉，文章只会变成另一种机器味。

真正的标准只有一条：**这段话，你会这么跟人讲吗？**
