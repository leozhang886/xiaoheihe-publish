《影之刃零》**10 月 29 日上午 10:00** 解锁（北京时间）。

¥268，S-GAME Studio 自己开发、自己发行。

预载已经开了。

**买之前，有两个数字得先看。**

图片来源：S-GAME 官方 Steam 商店截图。

# 一、第一个数字：300 GB

这是预载需要的可用空间。

游戏本体 **145 GB**。

**为什么预载要 300 GB？**

因为下载下来的是压缩包，安装时要解压。

同一份内容，压缩状态和展开后要同时放得下，装完才删压缩包。

**所以预留空间按解压后算，不是下载体积。**

这个坑我在别的游戏上踩过，那时候以为是自己盘满了。

# 二、第二个数字：必须是 SSD

官方配置里写得很直接：

> **游戏须安装在 SSD 上。**

不是"推荐"，是"须"。

这条越来越常见了。

但对国产单机来说，把 SSD 写进最低配置，这是头一回我记得的。

**如果你还在用机械盘装游戏，这台机器跑不了。**

# 三、配置档位

官方给的数字挺实在：

| | 最低 | 推荐 |
|---|---|---|
| CPU | i7-8700K / R5 3600 | i5-10600K / R5 5600X |
| 内存 | 16 GB | 16 GB |
| 显卡 | GTX 1660 6G / RX 5500 XT | RTX 3060 Ti / RX 6700 XT |
| 系统 | Win 10/11 64 位 | 同上 |
| 目标 | **1080p / 30 帧** | **1440p / 60 帧** |

# 四、这张表里有个细节

**最低配置只标了 30 帧，而且注明「开启超分辨率重建」。**

也就是说：跑最低配置，你得到的是 1080p、30 帧、还开了超分。

**这在一款动作游戏里是个不小的信息量。**

动作游戏对帧数敏感。30 帧打弹反、打闪避，容错会明显变低。

想玩得舒服，按推荐配置往上一点准备。

# 五、还有个前提条件

推荐配置写的是「1440p / 60 帧，开启超分」。

**这意味着它的性能依赖超分技术。**

如果你的显卡不支持 DLSS 或者 FSR，实际表现会打折扣。

1660 和 5500 XT 这两张卡：

- GTX 1660 不支持 DLSS（10 系、16 系都没有）
- RX 5500 XT 支持 FSR

同是最低配置，N 卡那一档会更吃力。

这一点官方表格里不会写。

# 六、外面的评价已经很热

媒体评测禁令解除后，反馈整体很好。

据 18183 转引 TheGamer 的报道：

- Metacritic 综合 **88 分**
- TheGamer 的作者给了满分，据说是他七年职业生涯第一次
- 评价里提到「史上最精彩的 Boss 战之一」

**但这是媒体视角。**

媒体评测用的机器、调的画面、玩的时长，都跟你不一样。

**你自己那台机器能不能跑，比任何评分都重要。**

# 七、要不要现在买

**先看两个数字：**

**一，你的盘是不是 SSD，还有没有 300 GB。**

不满足的话，买了也装不上。

**二，你的显卡在哪个档。**

低于 1660 这一档，建议等首日实测再决定。

国产 3A 首发翻车的先例不少。

等一天看评价不丢人，花 268 买回来发现跑不动才难受。

明天上午十点，你准备好了吗？
