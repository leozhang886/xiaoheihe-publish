机箱风扇装一堆，温度反而更高。

因为风道乱了。

# 一、基本原理

风道就是空气的路径：**前面进、后面出，下进、上出。**

**进风和出风要平衡，而且方向要一致。**

**如果进风比出风多，热气排不出去；出风比进风多，会从缝隙吸灰。**

# 二、够用的配置

大多数机箱，**两进一出或者三进两出就够了**。

- 前面板：进风，2 到 3 个
- 后部：出风，1 个
- 顶部：可选，出风

**重点是前面板要有足够的进风面积。**

# 三、比数量更重要的事

**进风口别被挡住。**

前面板如果是一整块玻璃，只能从侧边进气，那风量就大打折扣。

**这是很多美观机箱的真实问题。**

垫高机箱底部，让下面的进风口通畅，效果比加风扇明显。

# 四、一个反直觉的点

**风扇太多可能增加噪音，但不降低温度。**

因为总风量到一定程度后，散热瓶颈变成了散热器本身的导热能力。

再吹也吹不凉。

# 五、风扇朝向

**风扇有方向，别装反。**

风扇边框上通常有个箭头，标着风向。

**装反了就是对着吹，两个风扇对着顶。**

# 六、什么情况才需要加

- **显卡温度高，而且机箱摸起来烫**
- **CPU 散热器是塔式，但机箱没有出风**

**这两种情况加风扇有用。**

**如果温度本来正常，加了也只是更吵。**

# 七、一个容易被忽略的细节

**前置风扇别直吹硬盘架。**

很多机箱的硬盘架会挡住风，**风到了这儿就散了。**

能拆就拆，不能拆就把风扇位置往上挪。

# 八、我的建议

**先理顺方向，再考虑数量。**

**垫高机箱、清灰、把线整理一下**——这三件事经常比加风扇有效。

你现在几个风扇？
