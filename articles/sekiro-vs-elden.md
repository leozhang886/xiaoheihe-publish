同一个开发商，两个数字：

《艾尔登法环》180 小时。

《只狼》81 小时。

时间上法环赢了一倍多。

**但回想起来，我记得更清楚的，是只狼。**

# 一、法环给的是“世界”

法环的魅力在于大。

地图大、选择多、路线自由。

你可以绕开难点，换个方向再回来。

**你可以用各种构筑方案解决问题——法师、信仰、出血、盾戳。**

**它给了玩家很多"绕过去"的办法。**

**这就是它能玩 180 小时的原因。**

# 二、只狼给的是“一道门”

只狼没有构筑。

**只有一把刀，一个弹反，和一条路。**

打不过就是打不过，**不能换流派，不能堆等级，不能换个方向。**

你只能把那个 Boss 练会。

**所以它只需要 81 小时——因为你不能拖。**

# 三、为什么记得更清楚

**因为"卡住"的记忆比"通关"更牢。**

**法环里我击杀过几十个 Boss，大部分名字都忘了。**

**只狼里那几个卡了两天的，我到现在还记得它们的动作。**

**难度不是目的，是让记忆有重量的手段。**

# 四、这两种设计的取舍

| | 法环 | 只狼 |
|---|---|---|
| 自由度 | 高 | 低 |
| 时长 | 长 | 短 |
| 受众 | 广 | 窄 |
| 记忆强度 | 分散 | 集中 |

**法环更"友好"，只狼更"纯粹"。**

友好带来销量，纯粹带来记忆。

# 五、法环的代价

**选择太多，会让每次胜利都变得模糊。**

我打败一个 Boss 之后，经常想的是"这个构筑挺强"，而不是"我打得好"。

只狼不会给你这种模糊。

**赢了就是你练会了，输了就是你没练会。**

# 六、这不是说谁更好

两种设计服务两种人。

想慢慢探索、想用自己的方式解决问题的，法环更好。

**想体验"一寸一寸变强"的，只狼才对。**

**我两个都玩，但记住的只有后者。**

# 七、所以要问的是

**你玩游戏，是想"走完一段路"，还是想"翻过一堵墙"。**

**这两个目标会决定你觉得哪个更好。**

你的两个数字是多少？
