存档丢了想找回来，第一步是知道它在哪。

**PC 游戏的存档没有统一位置，至少散在四个地方。**

# 一、最常见：文档目录

```
C:\Users\<用户名>\Documents\My Games\<游戏名>
```

**很多游戏放这儿**，尤其是老一点的。

**这个目录会被 OneDrive 同步**，所以换电脑有时能自动带过去。

# 二、次常见：AppData

```
%APPDATA%\<游戏名>
%LOCALAPPDATA%\<游戏名>
```

**Windows 资源管理器地址栏直接输 `%APPDATA%` 就能跳过去。**

**这两个是隐藏目录，默认看不见。**

**AppData 不参与 OneDrive 同步**，所以换机器不会自动带。

# 三、Steam 用户数据

```
Steam\userdata\<一串数字>\<游戏 AppID>\
```

**这个目录里既有存档，也有设置。**

那串数字是你的 Steam 账号 ID，**不同账号不一样**。

**Steam 云存档同步的也主要是这里。**

# 四、游戏安装目录

**少数老游戏直接放安装目录下。**

现在这么做的少了，因为安装目录经常没有写权限。

# 五、怎么快速定位

**两个办法：**

- 游戏属性里有「浏览本地文件」，先看安装目录
- 网上搜「游戏名 + save location」，PCGamingWiki 通常有准确答案

**PCGamingWiki 最准，但全英文。**

# 六、云存档会覆盖本地吗

**会，而且是双向的。**

启动时如果云端版本更新，会拿云端的覆盖本地。

**所以出问题的时候，别急着启动游戏——一启动可能就把还能救的本地档覆盖了。**

**正确顺序是：先备份整个目录，再启动。**

# 七、我的建议

**常玩的游戏，把存档目录加个快捷方式到桌面。**

**每周复制一次到别的盘。**

**成本几秒钟，救的可能是几十小时。**

你知道自己常玩的游戏存档在哪吗？
